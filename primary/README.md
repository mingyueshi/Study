# 🎒 乐学堂 · 小学学习系统（当前：四年级）

> 本系统属于 [Study 多学段学习系统](../README.md) 的小学（primary）部分，后续将陆续建立初中、高中、大学与专业人员版本。

一个**离线可用、双击即开**的四年级学习系统：**📖 语文知识点总结**（人教版新课标四上）、**🔢 数学知识点总结**（北师大版新课标四上），外加 **📣 教材同步单词**、**🏮 成语本**、**✏️ 作文坊** 和 **🐉 成语接龙**。专为小学生设计：大按钮、大字号、可点读、可打印，家长可以随时扩充内容。

## 🚀 快速开始

- **学习导航**：双击 `index.html`（推荐用 Chrome / Edge / Safari 打开），从主页进入各个学习册；
- **语文知识点**：双击 `knowledge.html`，按人教版（统编版·新课标）四年级上册单元总结知识点；
- **数学知识点**：双击 `math.html`，按北师大版（新课标）四年级上册单元总结知识点；
- **教材同步单词**：双击 `english.html`，按外研版新标准三起（新课标）四年级上下册单元学习；
- **成语本**：双击 `idioms.html`；**作文坊**：双击 `writing.html`；**成语接龙**：双击 `chain.html`。

- 不需要安装任何软件，不需要联网；
- 换电脑时把整个 `primary` 文件夹一起拷走即可；
- 想在 iPad 上用？把文件夹放到 iCloud / AirDrop 到平板，用 Safari 打开对应页面。

## 📖 语文知识点（人教版 · 新课标四上）

以 2026 年秋季学期起使用的新修订教材目录编写（八个单元 27 课），把语文学习做成「知识点总结 + 复习」：

- **单元导航**：侧栏切换八个单元，每个单元有人文主题、学习重点和主题横幅插图，课文知识卡之外还有口语交际、习作、语文园地（快乐读书吧）要点；
- **课文知识卡**：每课一张卡——课文概览、内容梳理、主题感悟、重点词语（带释义）、四字词语、多音字、近义·反义、写法点睛、考点提示、背诵标注；全卡内容可点读；
- **课文图示**：观潮三阶段、蝙蝠与雷达对应、田忌赛马对阵表、爬山虎的脚、蟋蟀住宅剖面、精卫填海、长城结构、颐和园游览路线等 SVG 插图；
- **必背古诗文**：全书 9 首古诗 + 2 篇文言文（精卫填海、王戎不取道旁李），诗句逐行点读，文言文带注释；
- **日积月累**：好学名句、秋谚、俗语格言，逐句点读；
- **字词复习**：13 个多音字（双读音组词）+ 12 组形近字，期末复习专用。

> 知识点为精编总结，生字表、背诵篇目等细节请以孩子手中的课本为准。

## 🔢 数学知识点（北师大版 · 新课标四上）

同样以 2026 秋新修订版目录编写（八个单元 + 综合实践「编码」+ 数学好玩「数图形的学问」），把数学学习做成「知识点总结 + 复习」：

- **知识点卡**：共 37 个知识点，每条包含——知识要点（纲）、例题精讲（例：题目 + 步骤 + 答案）、易错提醒（错）、记忆口诀（诀）；每条可点读、可标记"已掌握"；
- **图示与互动演示**：数位顺序表、大数分级、线段/直线/射线、量角器、切开正方体等插图；**角的分类**（拖滑块转角）、**竖式逐步计算**、**路程=速度×时间**（小车动画）、**条形统计图换格子**、**数线段**、**三视图**共 6 个可操作的演示；
- **公式法则速查**：角与角度、运算律与性质、数量关系、凑整好朋友、积的变化规律，共 5 组；
- **易错诊所**：12 条「❌ 错误做法 → ✅ 正确做法」对照清单，考前过一遍；
- **搜索与打印**：全文搜索知识点、公式、易错点；一键把当前单元打印成复习纸。

> 单元目录：认识更大的数 / 线与角 / 整数乘法（二）/ 我们生活的空间（二）/ 运算律 / 图形的奥秘 / 运用数量关系解决问题 / 数据的表示和分析（一）+ 编码、数图形的学问。

## 🖥 自适应布局

- 首页以学习册卡片导航，窄屏自动改为单列；
- 语文知识点、数学知识点、教材同步单词、成语本、作文坊在 1000px 及以上使用分类侧栏与自适应卡片网格，目录可独立滚动；手机和平板使用可展开的分类目录，选完自动收起；

## 🐉 成语接龙

- **首尾同字、不重复**：输入四字成语，后一个成语的首字要与前一个的尾字相同；同音不同字不算接上。
- **两种玩法**：自己接龙，或与小龙轮流接。切换玩法会开始新一轮，两种玩法分别保存最佳纪录。
- **释义提示与点读**：遇到难题可查看最多 3 个候选，点一下填入，再确认接上；当前成语和接龙轨迹都可朗读。
- **719 条内置词库**：复用成语本及其拓展释义，另补常见接龙词；未收录的词会提示换一个。
- **本地续玩**：本轮接龙、最佳纪录和累计接对数自动保存，刷新后可接着玩。

接龙补充词位于 `chain-data.js`，完整词卡优先使用 `idioms-data.js`。修改词库或规则后运行 `node test/test-chain.js`。

## ✏️ 作文坊（写作学习）

- **六大分类 15 个题目**（对应四年级课本习作）：写人、写事、写景、写物、想象、应用文；
- 每个题目一张**写作锦囊卡**：🎯 写作目标 → 开头/中间/结尾三步怎么写（可点读）→ 好词好句（可点读）→ **带点评的范文**（可展开、可整篇朗读）→ 小练笔任务；
- **素材百宝箱**：6 种好开头、5 种好结尾、四类好词、比喻拟人好句，点一下就能听；
- **🎲 灵感抽签**：不知道写什么？抽一个题目，配好目标，一键开写；
- **📓 我的作文本**：真正动笔写——实时显示字数、段落数、用到的好词，可保存到本机、随时修改，还能朗读自己写的作文。

## ✨ 系统特性

- **知识点总结**：语文、数学按教材单元沉淀成可翻阅、可点读、可打印的复习材料，学完一课可打 ✓，进度自动保存；
- **点读朗读**：知识点、同步单词、成语本均可点击 🔊 朗读（使用系统自带语音，中文自动切换中文发音人）；
- **全文搜索**：每个学习册都有搜索框，找不到就搜；
- **打印复习纸**：语文、数学知识点都能按单元打印，自动隐藏导航与按钮；
- **本地存档**：所有进度保存在本机浏览器中，换浏览器/清缓存会重置。

## 🔊 关于发音

- 系统会**自动挑选你 Mac 上质量较好的英语发音人**（优先 Samantha / Ava / Google US English 等），中文朗读自动切换中文发音人；
- 教材同步单词页顶部有**发音人下拉框**，切换后会读一句试听例句，选择会记住；
- 想要更自然的发音，可在「系统设置 → 辅助功能 → 系统声音」的**管理声音**里下载高质量语音，下载后刷新页面即可选用。

## 🧭 建议的使用节奏（短时高频）

1. **每天 15–20 分钟**：翻开一个知识点单元读一读，配合成语本、单词点读，不求多、求坚持；
2. 学完一课在知识点页打 ✓，看着进度一点点填满很有成就感；
3. 周末把本周单元再过一遍（重点看「错」「⚠️」部分）；
4. 考前用**必背古诗文**、**公式法则速查**和**易错诊所**做总复习，把薄弱单元打印成复习纸。

## ➕ 家长如何添加内容

### 语文知识点（knowledge-data.js）

数据按 `units`（八个单元）、`poems`（必背古诗文）、`sayings`（日积月累）、`polyphonic`（多音字）、`similar`（形近字）组织。每篇课文一张知识卡：

```js
{
  id: '1', title: '观潮', tag: '精读', author: '赵宗成 朱明元',
  overview: '一句话概括课文写什么。',
  main: ['内容梳理第一条', '内容梳理第二条'],
  theme: '中心思想 / 道理感悟。',
  words: [ ['奇观', '释义'], ['人声鼎沸', '释义'] ],
  poly: [ ['号', 'háo', '号叫', 'hào', '号召'] ], // 可省略
  synant: [ ['宽阔', '宽敞、宽广', '狭窄'] ],     // 可省略
  craft: '写法点睛。',
  tips: ['考点提示 1', '考点提示 2'],
  recite: '第 3、4 自然段',                      // 可省略
}
```

单元级的 `goals`（学习重点）、`oral`（口语交际）、`writing`（习作）、`garden`（语文园地）、`book`（快乐读书吧）按需增删。修改后运行 `node test/test-knowledge.js`。

### 数学知识点（math-data.js）

数据按 `units`（十个板块）、`formulas`（公式速查）、`mistakes`（易错诊所）组织。每个知识点一张卡：

```js
{
  id: 'mu1-1', title: '数位顺序表与计数单位',
  overview: '一句话概述这个知识点。',
  items: ['要点一', '要点二', '要点三'],
  example: { q: '例题', a: '答案', steps: '解题步骤' },
  mistakes: ['易错提醒'],        // 可省略
  recall: '记忆口诀',            // 可省略
}
```

公式速查按 `[名称, 式子]` 成对填写；易错诊所每条包含 `unit`（所属单元）、`wrong`（错误做法）、`right`（正确做法）。修改后运行 `node test/test-math-knowledge.js`。

### 作文坊（writing-data.js）

写作题目按「写人、写事、写景、写物、想象、应用文」分类（当前 15 题）。添加一个题目：

```js
{ title: '难忘的一天', goal: '写清楚这一天发生了什么、你的心情。',
  outline: [ { label: '开头', text: '……' }, { label: '中间', text: '……' }, { label: '结尾', text: '……' } ],
  words: ['好词1', '好词2', '好词3'],
  sentences: ['一个好句', '另一个好句'],
  model: '范文正文（用空行分段，不少于 120 字）',
  comment: '点评：范文好在哪里',
  task: '小练笔：……' },
```

素材百宝箱在同文件底部的 `WRITING_MATERIALS` 里添加。

### 成语本（idioms-data.js）

成语按主题分类（当前 **15 类 257 条**）。每条成语的卡片包含：**拼音、释义、逐字点读、典故故事、例句、近义/反义成语（带中文解释）**。添加一条：

```js
{ idiom: '雪中送炭', pinyin: 'xuě zhōng sòng tàn', zh: '下雪天给人送炭，比喻在别人急需时给予帮助。',
  chars: [ { t: '雪', d: '下雪' }, { t: '炭', d: '木炭' }, { t: '送', d: '送去' }, { t: '炭', d: '炭火' } ],
  example: '同学忘带彩笔，我借给他，这就是雪中送炭。',
  syn: ['锦上添花'], ant: ['雪上加霜', '火上浇油'] },
```

- `chars` 的每个 `t` 必须和成语对应位置的字相同（测试会检查）；
- 近反义成语若不在书内，要在文件底部的 `IDIOM_ZH` 词典里补一条中文解释。

### 教材同步单词（english-data.js）

按外研版《英语（新标准）》三年级起点新课标四年级教材组织，上册 6 个单元、下册 6 个单元，共 **12 单元 306 条词汇/短语**。添加词汇时在对应单元的 `words` 数组中使用简写格式：

```js
w('sunflower', '/ˈsʌnflaʊə/', 'n. 向日葵', '🌻', 'sun|flower',
  'sun（太阳）+ flower（花），向着太阳的花就是向日葵。'),
```

- 第 5 个参数用 `|` 分段，留空则整词认读；拆分后必须能还原原词；
- 修改后运行 `node test/test-english.js`。

> 注意：修改后刷新浏览器页面即可生效；如果页面打不开，多半是漏了逗号或引号，按浏览器控制台的报错行号检查。

## 🧩 设计思路

- **重"总结"不重"刷题"**：语文、数学都按教材单元沉淀成可翻阅、可朗读、可打印的知识点材料，配合成语、写作、单词等专题学习册使用；
- **游戏化但不喧宾夺主**：已掌握 ✓、连读、进度计数只服务于"坚持"，不设排行榜、不制造焦虑；
- **无账号无联网**：数据在本机，孩子用得专注，家长管得放心。
