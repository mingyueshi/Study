数据库与多账号版本见 [`../primary-system/`](../primary-system/README.md)：统一课程目录、Nova 后台、个人进度与基础内容阅读已经建立。本目录继续保留离线页面和原有互动，作为内容来源及后续迁移参考。

一个**离线可用、双击即开**的四年级学习系统：**📖 语文知识点总结**（人教版新课标四上）、**🔢 数学知识点总结**（北师大版新课标四上）、**🌍 地理探索**（小学地理启蒙）、**🔭 天文探索**（小学天文启蒙）、**🏛️ 历史长廊**（小学历史启蒙）、**🕰️ 历史双轨时间轴**（中外同期对照）、**📚 文学常识**（小学文学启蒙）、**🧪 科学实验室**（小学科学启蒙），外加 **📣 教材同步**、**📝 英语语法**、**🔤 英语音标**、**📘 场景单词**、**🏮 成语本**、**✏️ 作文坊** 和 **🐉 成语接龙**。专为小学生设计：大按钮、大字号、可点读、可打印，家长可以随时扩充内容。

## 🚀 快速开始

- **学习导航**：双击 `index.html`（推荐用 Chrome / Edge / Safari 打开），从主页进入各个学习册；
- **语文知识点**：双击 `knowledge.html`，按人教版（统编版·新课标）四年级上册单元总结知识点；
- **数学知识点**：双击 `math.html`，按北师大版（新课标）四年级上册单元总结知识点；
- **地理探索**：双击 `geo/index.html`，按八大主题学习地理知识，配实景照片、讲解音频与动画演示；
- **天文探索**：双击 `astro.html`，按九大太空基地学习天文宇宙知识，末站「未解之谜」讲暗物质、暗能量等前沿谜题；
- **历史长廊**：双击 `history/index.html`，按时间顺序学习中华历史知识，配文物照片、讲解音频与动画演示；
- **历史双轨时间轴**：双击 `history-timeline/index.html`，竖版时间轴左看中国、右看世界，点「对照」跳到同一时期的大事；
- **中国地图系统**：双击 `geo-map/index.html`，地图编排演示第一站的多页面系统：中国地图主页换三层认省份山河邻居，省域站逐省细看，世界地图筹备中；
- **文学常识**：双击 `lit.html`，按八大文学苑学习文学常识；
- **科学实验室**：双击 `sci.html`，按八大科学实验室学习科学知识；
- **教材同步**：双击 `english.html`，按外研版新标准三起（新课标）四年级上下册单元学习单词与课文；
- **英语语法**：双击 `grammar/index.html`，按八大主题学习小学语法，每点含规则讲解、句型结构、例题与巩固题；
- **英语音标**：双击 `phonetics/index.html`，按八大主题学完全部 48 个音标，每点含发音要领、例词与辨音巩固题；
- **场景单词**：双击 `words.html`，按教室、食物、农场、社区、交通、海洋、太空等 38 个生活场景学习 480 个单词，与教材同步分别记录掌握进度；
- **成语本**：双击 `idioms.html`；**作文坊**：双击 `writing.html`；**成语接龙**：双击 `chain.html`。

- 不需要安装任何软件，不需要联网；
- 换电脑时把整个 `primary` 文件夹一起拷走即可；
- 想在 iPad 上用？把文件夹放到 iCloud / AirDrop 到平板，用 Safari 打开对应页面。

## 📖 语文知识点（人教版 · 新课标四上）

- **课文图示**：观潮三阶段、蝙蝠与雷达对应、田忌赛马对阵表、爬山虎的脚、蟋蟀住宅剖面、精卫填海、长城结构、颐和园游览路线等 SVG 插图，其中「田忌赛马」配**调兵对阵**互动演示（点「下一步」看孙膑怎么反败为胜）；

```js
  synant: [ ['宽阔', '宽敞、宽广', '狭窄'] ],     // 可省略

  authorLife: '生卒年 / 身份',                   // 可省略（有作者时建议填）

  excerpts: ['原文金句一', '原文金句二'],          // 可省略
  facts: ['真实百科一', '真实百科二'],             // 可省略
  videos: [{ bvid: 'BV…', title: '视频标题', up: 'UP主', dur: 300, note: '说明' }], // 可省略

```

古诗文在 `poems` 里额外带 `life`/`bio`（诗人或出处小传）、`bg`（创作背景）与 `videos`，方便日后整体导出到 `primary-system`。单元级的 `goals`（学习重点）、`oral`（口语交际）、`writing`（习作）、`garden`（语文园地）、`book`（快乐读书吧）按需增删。修改后运行 `node test/test-knowledge.js`。

### 数学知识点（math-data.js）

数据按 `units`（11 个板块：八个单元 + 编码 + 数图形的学问 + 导航给的时间准吗）、`formulas`（公式速查）、`mistakes`（易错诊所）、`banners`（情境照片横幅）、`videos`（教学视频清单）组织。每个知识点一张卡：

```js
  example: { q: '例题', a: '答案', steps: '解题步骤' },
```

知识点情境照片（`life` + 照片文件）、单元横幅（`banners`）与教学视频（`videos`）已直接收录在 `math-data.js` 内，`math-figures.js` 只负责 SVG 图示与横幅渲染，方便日后整体导出。修改后运行 `node test/test-math-knowledge.js`。

公式速查按 `[名称, 式子]` 成对填写；易错诊所每条包含 `unit`（所属单元）、`wrong`（错误做法）、`right`（正确做法）。修改后运行 `node test/test-math-knowledge.js`。

地理是自包含子目录：数据在 `geo/content.js`（章节与知识点归档）和 `geo/knowledge-core.js`（第一至四章）、`geo/knowledge-regions.js`（第五至八章）。每个知识点一段：

## 🧩 设计思路

- **重"总结"不重"刷题"**：语文、数学、地理、天文、历史、文学、科学都按教材单元/主题沉淀成可翻阅、可朗读、可打印的知识点材料，配合成语、写作、单词等专题学习册使用；
- **游戏化但不喧宾夺主**：已掌握 ✓、连读、进度计数只服务于"坚持"，不设排行榜、不制造焦虑；
- **无账号无联网**：数据在本机，孩子用得专注，家长管得放心。
