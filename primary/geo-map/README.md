# 中国地图系统（多页面编排演示）

与 `primary/geo/`（知识精讲式编排）并列的另一种地理编排，是「地图编排」系列的完整两站。地理知识是一个庞大的体系，一个页面装不下，所以这套编排是**多页面系统**：门户页做总导航；第一站中国地图换图层纵览全局，三十四个省域站逐省细看；第二站世界地图认七大洲四大洋、点世界之最、看中国站在世界什么位置。

## 页面

| 页面 | 装什么 |
| --- | --- |
| `index.html` | 系统门户：两个入口卡（中国地图 / 世界地图筹备中）+ 三十四个省域站导航 + 使用指南 |
| `china.html` | 中国地图主页：三层地图（省级行政区按四大区域着色 / 山河大地三级阶梯＋45 处标记 / 邻居按方位站队）+ 找一找游戏 + 7 张地图口诀卡 |
| `province.html?adcode=` | 省域站详情页（34 省共用模板）：单省档案 + 迷你地图（本省高亮，其余省份可点击跳站）+ 记一记要点 + 上一站/下一站 |
| `world.html` | 世界地图：七大洲 / 世界之最 / 中国与世界三个图层 + 找一找 + 中国×世界对照卡 |

所有页面共享顶部系统导航条与页脚互链，可从任意一页到达其他页面；`province.html` 无效参数时回退为省域站列表。

## 玩法

- **三个图层**：中国地图页工具栏互斥切换「省级行政区 / 山河大地 / 我们的邻居」，每次只看一类东西；切换后档案卡回到该图层的引导语。
- **档案卡**：点省份看简称、类型、省会、方位小知识，点「进省域站细看 →」直达该省的站；点山河湖海与邻居看位置与一句话介绍。
- **山河标记**：45 处可点击——长江黄河、黑龙江、珠江、淮河、京杭大运河，主要阶梯界山（昆仑、祁连、大兴安岭、太行、巫山、雪峰山、南岭等），四大高原、三大平原、四大盆地，五大淡水湖，四大海域与台湾岛、海南岛、钓鱼岛、赤尾屿。
- **找一找**：从题库随机 5 题（省份、山河、邻居混搭），点对了亮绿光得一分，答错给方位提示，结束按得星数复盘。
- **省域站**：门户省域站格子、地图档案卡都能进站；站内有档案、记一记三要点和迷你地图（点其他省份跳站），底部上一站/下一站按行政区划代码顺序环游全国。
- **七大洲图层**：177 个国家和地区按所属大洲着色，点国家或四大洋亮档案卡；
- **世界之最图层**：珠穆朗玛峰、尼罗河、亚马孙河、撒哈拉沙漠、马里亚纳海沟、大堡礁等 10 处标记可点击；
- **中国与世界图层**：金色高亮中国（含台湾省），点它看面积排名、东八区与邻国回顾；
- **世界找一找**：大洋、世界之最与大国混搭，随机 5 题一轮；
- **中国×世界对照卡**：长江×尼罗河、珠峰×勃朗峰、陆地面积第三，页面上可直接验证。

## 编排边界

- 地图为**教学示意版**：省级行政区轮廓来自公开边界数据（阿里云 DataV），Douglas–Peucker 简化到约 2 千米精度；山脉、河道为近似示意折线。
- 南海诸岛与十段线按制图惯例画在右下角小图（数据从海南省要素中拆出）；台湾岛、海南岛、钓鱼岛、赤尾屿标注在主图上。
- 省份按四大地理区域着色，个别跨区域省区只按主要部分归类。
- 数字一律用通行约数（长江约 6300 千米、黄河约 5464 千米、珠峰 8848.86 米）。
- 离线优先：无外链、无图片、无网络依赖，双击任意页面即可打开，整目录可单独拷走。

## 数据维护

- 省份 `id` 为 `p＋adcode`，必须与 `china-geo.js` 里的 `provinces` 键一一对应（34 个）；山河标记 `f数字`、邻国 `n数字`。
- 省份 `facts` 是省域站「记一记」的五条要点：依次讲地形与位置、代表山河湖海、人文与物产、气候物产、趣味名胜，测试限定每省恰 5 条非空字符串。
- `world-data.js` 的 `GM_COUNTRY_META` 键是 world-geo.js 的英文名，值为 [中文名, 大洲 id]，测试核对两边一一对应；台湾写作「中国台湾省」，地跨两洲的国家按习惯划分归入其一。
- 新增世界之最标记用 `wf数字`、大洋用 `o数字`；世界投影为等经距画法，坐标范围东经西经 ±180°、北纬 87° 至南纬 73°。
- 站序按行政区划代码排列（`province-app.js` 内排序）；新增省份条目后，省域站、门户格子与翻页器自动更新。
- 新增页面时：骨架 HTML 引本目录脚本、带 `gm-sysnav` 导航条并在测试 `PAGE_REFS` 登记；页面级逻辑放独立 `*-app.js`，复用 `shared.js` 与 `styles.css`，不复制地图绘制代码。
- `china-geo.js` 请勿手工编辑；重新生成：

```sh
python3 primary/geo-map/scripts/build-geo.py <100000_full.json 路径>
# 不给路径会自动从阿里云 DataV 下载源文件
python3 primary/geo-map/scripts/build-world.py <countries-110m.json 路径>
# 不给路径会自动从 jsDelivr 下载 world-atlas 源文件
```

- 字符串里用中文标点（「」、，、：），不要英文引号和裸换行——测试会拦截。
- 修改后运行：

```sh
node primary/test/test-geo-map.js
```
