# 历史知识精讲

独立的历史知识编排演示，复用 `primary-system` 的宽屏主题。入口为 `index.html`，保留8章、37个原主题ID。正文以知识点为主线，不依赖 `primary/` 的脚本、样式或素材。

## 知识编排

每条直接显示概念与核心史实、3—5项必须掌握的结论、年代和关键数据、对比表、例题分析、易错辨析与巩固题。时间、制度、因果、材料证据相互联系。例题答案可展开，知识正文不放在弹窗里。

上古传说与确证史实分开；夏的年代加“约”，二里头对应问题保留研究边界。说明蔡伦改进造纸、兰亭原作不传、司南照片为现代复原、隋唐与前后政权的年代交叠、元朝与蒙古帝国的区别。除明确标注同一时间刻度的图外，示意图不按年代时长或地图距离比例绘制。

37张对比或时间表、11种文物与实景照片、9幅知识图解、3组动画、4段本地复习音频、汉长城短片、3条央视节目链接及每点的机构资料辅助正文。音频是本页编写摘要的中文语音合成，提供文字稿；不是官方原声。图片可以放大，视频和动画按知识点打开。

## 自测记录

答对相应知识点的巩固题后，自动保存该点记录。键为 `history-knowledge-progress-v1`，按浏览器与站点保存，不同步账号。旧的 `history-explorer-passport-v1` 八章印章不删除、不自动换算。答对一道题只代表本次自测通过。

## 本地预览与模板

在仓库根目录启动临时静态服务，例如 `python3 -m http.server 8768 --bind 127.0.0.1`，访问 `http://127.0.0.1:8768/history-explorer/`。

```sh
python3 history-explorer/scripts/export_django.py
python3 history-explorer/scripts/export_django.py --check
```

输出模板仅保留专题容器和资源引用，继承 `base.html`，不复制公共页头页脚或加载 `platform-theme.css`。媒体、音频、文档根据脚本位置定位，支持深层路由。

本次只修改独立的 `history-explorer/`，没有为主项目添加路由、视图、模型或数据库内容。正式接入仍需在真实Django页面核对全局导航、静态资源和账号归属。
