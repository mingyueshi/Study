# 历史时间轴系统（多页面编排演示）

与 `primary/history/`（知识精讲式编排）并列的另一种历史编排演示。历史知识是一个庞大的体系，一个页面装不下，所以这套编排是**多页面系统**：门户页做总导航，双轨时间轴纵览全局，九个时代站逐段细看，朝代更替页补上公元纪年这把尺子。竖版布局、时间从上往下流动，左轨中国史（朱红），右轨世界史（青蓝），中间一条虚线时间脊轴，两边同一时期的大事用编号「对照」互相跳转。

## 页面

| 页面 | 装什么 |
| --- | --- |
| `index.html` | 系统门户：两个入口卡 + 九个时代站导航 + 数据规模 |
| `timeline.html` | 双轨时间轴主页：9 个时代带 126 件大事、30 组同期对照、朝代速览条 |
| `era.html?era=时代id` | 时代站详情页（9 个时代共用模板）：单时代双轨事件 + 这一站的对照 + 上一站/下一站 |
| `dynasties.html` | 朝代更替：公元纪年小课堂 + 十六个朝代竖版更替轴 |

所有页面共享顶部系统导航条与页脚互链，可从任意一页到达其他页面；`era.html` 无效参数时回退为时代站列表。

## 玩法

- **双轨全览 / 只看一条线 / 只看对照时刻**：时间轴页顶部筛选按钮切换视角，窄屏下自动变为单列（中国线在上、世界线在下）。
- **时代站**：时间轴每个时代头上的「进时代站细看 →」和门户页的时代站格子都能进站；站内有该时代全部双轨事件、这一站的同期对照卡（点击高亮两侧）与上一站/下一站翻页。
- **同期对照**：30 组对照各有一个编号（①②③…），出现在两张卡右上角；点卡片下方的对照按钮会滚动到对面轨道并高亮，底部弹出「同一时期」一句话说明。
- **朝代速览**：时间轴页首一条横排的 16 朝代链条（夏到清，附年代与分段说明），按所处时代带配色，点朝名直达时间轴对应阶段；下方附朝代歌口诀。
- **朝代更替子页**：先讲「什么是公元前、公元后」（时间数轴、三条计算规则、练一练），再用竖版更替轴展示 16 个朝代怎么建立、怎么谢幕。
- **时代站导航**：吸顶工具栏有 9 个时代带跳转按钮，中间脊轴的圆点对应时代站。
- **首页速览**：3 组精选对照（郑和×哥伦布、四库全书×蒸汽机、孔子×释迦牟尼）放在页首，点击直达。

## 编排边界

- 年代一律用通行约数（夏朝约前 2070 年），传说时代内容明确标注「传说时代」。
- 上下距离不代表时间长短，卡片只按时代顺序排列。
- 对照组的两侧年代差控制在同一时期范围内（测试限定 350 年以内）。
- 涉及殖民、战争等表述保持中性、讲给孩子听的语气（如哥伦布「也带来了殖民和灾难」）。
- 离线优先：无图片、无外链、无网络依赖，双击任意页面即可打开，整目录可单独拷走。

## 数据维护

- 事件字段：`id`（`tc数字`＝中国轨 / `tw数字`＝世界轨）、`track`、`era`、`year`（展示年代）、`sort`（排序数字，公元前记负数，长时段取中点）、`tag`（朝代/文明）、`icon`（单个 emoji）、`title`、`text`。
- 朝代速览在 `content.js` 的 `TIMELINE_DYNASTIES`：字段 `name`、`span`（展示年代）、`sort`（起算年代，公元前记负数）、`era`（指向时代带，点朝名跳转的落点）、可选 `note`（分段说明，如「西汉 · 东汉」）。
- 朝代更替子页在 `dynasty-data.js`：`DYNASTY_BANDS` 字段 `id`、`name`、`span`、`startYear`/`endYear`（公元前记负数，须满足 start < end）、`duration`、`rise`（建立）、`fall`（灭亡）、`capital`、可选 `note`；`DYNASTY_TRANSITIONS` 的 `to` 必须是 `from` 的下一个朝代；`CALENDAR_AXIS` 中「前 1 年」必须紧挨「公元 1 年」（直观呈现没有公元 0 年）。
- 同一时代、同一轨道内事件按 `sort` 升序排列；每组 `TIMELINE_PAIRS` 的 `china`/`world` 必须各指向对应轨道、且属同一时代。
- 新增页面时：骨架 HTML 引本目录脚本、带 `tl-sysnav` 导航条并在测试 `PAGE_REFS` 登记；页面级逻辑放独立 `*-app.js`，复用 `shared.js` 与 `styles.css`，不复制事件卡渲染代码。
- 字符串里用中文标点（「」、，、：），不要英文引号和裸换行——测试会拦截。
- 修改后运行：

```sh
node primary/test/test-timeline.js
```
