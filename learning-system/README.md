# 🎒 乐学堂 · 四年级学习系统

一个**离线可用、双击即开**的四年级语文 / 数学 / 英语练习系统，外加 **📘 单词本**、**🏮 成语本** 和 **✏️ 作文坊** 三个学习册。专为小学生设计：大按钮、大字号、即时鼓励、星星与打卡激励，家长可以随时扩充题库和词库。

## 🚀 快速开始

- **练习系统**：双击 `index.html`（推荐用 Chrome / Edge / Safari 打开）；
- **单词本**：双击 `words.html`，或从乐学堂首页点「📘 单词本」进入；
- **成语本**：双击 `idioms.html`，或从乐学堂首页 / 单词本点「🏮 成语本」进入；
- **作文坊**：双击 `writing.html`，或从乐学堂首页 / 其他学习册点「✏️ 作文坊」进入。

- 不需要安装任何软件，不需要联网；
- 换电脑时把整个 `learning-system` 文件夹一起拷走即可；
- 想在 iPad 上用？把文件夹放到 iCloud / AirDrop 到平板，用 Safari 打开对应页面。

## ✏️ 作文坊（写作学习）

- **六大分类 15 个题目**（对应四年级课本习作）：写人、写事、写景、写物、想象、应用文；
- 每个题目一张**写作锦囊卡**：🎯 写作目标 → 开头/中间/结尾三步怎么写（可点读）→ 好词好句（可点读）→ **带点评的范文**（可展开、可整篇朗读）→ 小练笔任务；
- **素材百宝箱**：6 种好开头、5 种好结尾、四类好词、比喻拟人好句，点一下就能听；
- **🎲 灵感抽签**：不知道写什么？抽一个题目，配好目标，一键开写；
- **📓 我的作文本**：真正动笔写——题目+正文，实时显示**字数、段落数、用到的好词**，并给出温和的小提示（分段建议、标点提醒）；写完可保存到本机、随时打开修改，还能**朗读自己写的作文**；
- 未保存的草稿会自动暂存，意外关闭页面也不怕。

## 📚 三科玩法（以三科为例，架构可扩展到任意科目）

| 科目 | 玩法 | 内容依据 |
|---|---|---|
| 📖 语文 | 看拼音写词 · 古诗天地 · 成语填空 · 字词诊所 | 统编版四年级上下册词语表、必背古诗、日积月累 |
| 🔢 数学 | 口算挑战 · 竖式计算 · 应用题乐园 · 单位换算 · 口算打印卡 | 人教版四年级：三位数乘两位数、除数是两位数的除法、公顷与平方千米、小数加减、鸡兔同笼、优化等 |
| 📣 英语 | 单词认读（可听发音）· 看词说英 · 单词拼写 · 情景对话 · 单词卡 | PEP 四年级上下册核心词汇与句型 |

> 数学口算由程序随机生成，**永远做不完也永远不重复**；应用题、古诗、成语等来自内置题库。

## ✨ 系统特性

- **每日任务**：每科每天 10 题，三科完成可领取 ⭐+10 奖励，连续打卡点亮 🔥；
- **错题本**：答错的题自动收录，答对 2 次自动"消灭"，形成复习闭环（间隔复习）；
- **激励体系**：答对得星、满分加星、8 枚成就徽章、撒花动画与音效；
- **英语朗读**：单词和句子可点击 🔊 朗读（使用系统自带语音，英语声音建议在系统设置中确认已安装英文语音）；
- **口算打印卡**：一键生成 40 道口算题 + 答案页，打印成纸质卷子，适合每日 5 分钟限时练；
- **本地存档**：所有进度保存在本机浏览器中，换浏览器/清缓存会重置（设置里有"清空进度"）。

## 🔊 关于发音

- 系统会**自动挑选你 Mac 上质量较好的英语发音人**（优先 Samantha / Ava / Google US English 等），中文注释朗读自动切换中文发音人；
- 单词本顶部（以及乐学堂「⚙️ 设置」里）有**发音人下拉框**，切换后会读一句试听例句，选择会记住；
- 想要更自然的发音，可在「系统设置 → 辅助功能 → 系统声音」的**管理声音**里下载高质量英语语音（推荐 Ava、Samantha 或 Premium 系列），下载后刷新页面即可在下拉框中选用；
- 个别拆分段（如 Wednesday 的 `Wed`）字母组合无法直接朗读，数据里用 `say` 指定了它实际读的音（读作 when）。

## 🧭 建议的使用节奏（短时高频）

1. **每天 15–20 分钟**：每科一组（10 题），不求多、求坚持；
2. 口算挑战可以掐表计时，记录"今天用了几分钟"；
3. 周末把**错题本**清一遍（答对 2 次才会消失，确保真的掌握）；
4. 家长每天打印一张口算卡作为热身，屏幕练习作为巩固。

## ➕ 家长如何添加内容

### 作文坊（writing-data.js）

写作题目按「写人、写事、写景、写物、想象、应用文」分类（当前 15 题，对应四年级课本习作）。添加一个题目：

```js
{ title: '难忘的一天', goal: '写清楚这一天发生了什么、你的心情。',
  outline: [ { label: '开头', text: '……' }, { label: '中间', text: '……' }, { label: '结尾', text: '……' } ],
  words: ['好词1', '好词2', '好词3'],
  sentences: ['一个好句', '另一个好句'],
  model: '范文正文（用空行分段，不少于 120 字）',
  comment: '点评：范文好在哪里',
  task: '小练笔：……' },
```

素材百宝箱（好开头/好结尾/好词/好句）在同文件底部的 `WRITING_MATERIALS` 里添加。

### 成语本（idioms-data.js）

成语按主题分类（当前 6 类 53 条：寓言故事、数字成语、动物成语、身体成语、学习品质、季节天气）。每条成语的卡片包含：**拼音、释义、逐字点读（记）、典故故事（📜 可点读）、例句（可点读）、近义/反义成语（可点读，带中文解释）**。添加一条：

```js
{ idiom: '雪中送炭', pinyin: 'xuě zhōng sòng tàn', zh: '下雪天给人送炭，比喻在别人急需时给予帮助。',
  chars: [ { t: '雪', d: '下雪' }, { t: '炭', d: '木炭' }, { t: '送', d: '送去' }, { t: '炭', d: '炭火' } ],
  example: '同学忘带彩笔，我借给他，这就是雪中送炭。',
  syn: ['锦上添花'], ant: ['雪上加霜', '火上浇油'] },
```

- `chars` 的每个 `t` 必须和成语对应位置的字相同（测试会检查）；
- 近反义成语若不在书内，要在文件底部的 `IDIOM_ZH` 词典里补一条中文解释（`test/test-idioms.js` 会检查覆盖）。

### 单词本（words-data.js）

单词按「单元」组织，每个单元一个主题（如教室、食物、星期）。加一个单词只需往对应单元的 `words` 数组里加一条：

```js
{ en: 'banana', ipa: '/bəˈnɑːnə/', zh: 'n. 香蕉', emoji: '🍌',
  parts: [ { t: 'ba', d: '/bə/' }, { t: 'na', d: '/ˈnɑː/' }, { t: 'na', d: '/nə/' } ],
  memo: '三段 ba-na-na，像小船弯弯。a banana 一根香蕉要加 a。',
  related: ['apple', 'orange', 'fruit'] },
```

字段说明：

| 字段 | 作用 | 必填 |
|---|---|---|
| `en` | 单词本体，也是点读内容，**全书不能重复** | ✅ |
| `ipa` | 音标，用 `/ /` 包裹 | ✅ |
| `zh` | 中文注释，建议带词性（n. / adj. / v.） | ✅ |
| `emoji` | 大示意图（留空 `''` 会自动显示首字母卡片） | 建议 |
| `img` | 图片地址，填了优先于 emoji（支持同目录图片文件） | 可选 |
| `parts` | 拆分记忆：`t` 是拆出的音节/词根（**点击可读**），`d` 是该段说明；可选 `say`：当拆分段直接朗读会很怪时（如 `Wed`、`owl`），用它指定实际朗读的文本（如 `say:'when'`） | ✅ |
| `memo` | 拆分解释：一句话记忆故事 | ✅ |
| `related` | 相关词数组（**点击可读**）。中文解释自动生成：书内词取它自己的 `zh`，书外拓展词查文件底部的 `WORD_ZH` 词典——**用了新的拓展词时记得在那里补一条**（`test/test-words.js` 会检查覆盖） | ✅ |

新增一个单元：复制一个单元对象，改 `id`（不重复）、`name`、`zh`、`emoji`、`color` 即可，首页单元条自动出现。当前示例共 **17 个单元 205 词**：教室、文具、朋友、家、食物、家庭、星期、季节天气、动物、身体、颜色、数字、学校场所、服装、时间作息、水果、常用动作——星期含完整 7 天、季节含完整四季、数字含 1–12，相关词互相串联。

### 练习题库（data.js）

**加英语单词**——在 `EN_WORDS` 里加一行：

```js
{ en: 'grass', zh: '草' },
```

**加应用题**——在 `MATH_WORD_BANK` 里加一条（`a` 是答案，`ex` 是讲解）：

```js
{ q: '商店有 360 瓶牛奶，每箱装 24 瓶，一共有多少箱？', a: '15', ex: '360 ÷ 24 = 15（箱）。' },
```

**加古诗 / 成语 / 拼音词**——分别在 `POEMS`、`IDIOMS`、`CN_WORDS` 数组里照格式添加。

**加一整门新科目**（如科学）——在 `SUBJECTS` 数组里复制一个科目对象，改 id、名字和玩法即可，首页会自动出现新卡片，错题本、每日任务自动支持。

> 注意：修改后刷新浏览器页面即可生效；如果页面打不开，多半是漏了逗号或引号，按浏览器控制台的报错行号检查。

## 🧩 设计思路

- **游戏化但不喧宾夺主**：奖励体系（星星/打卡/徽章）只服务于"坚持"，不设排行榜、不制造焦虑；
- **错题闭环**：做错 → 收录 → 重做 → 答对两次 → 消灭，符合间隔重复记忆规律；
- **生成式口算**：计算能力靠"天天练"，程序生成保证每天题目新鲜；
- **无账号无联网**：数据在本机，孩子用得专注，家长管得放心。
