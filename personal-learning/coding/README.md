# 语言与框架学习

入口：[学习路线](index.html)。面向日常开发，包含 **Python、Vue、Django 三条路线，各 10 节课，共 30 节课与 30 道自检题，另有 3 个可下载实操项目**。

## 内容与实操

| 路线 | 主要内容 | 配套项目 |
| --- | --- | --- |
| Python | 解释器与环境、类型、流程、容器、函数、导入、JSON 文件、异常、类与类型提示、测试 | 命令行任务清单，标准库实现，含 5 项测试 |
| Vue | Vue 3 单文件组件、响应式、模板列表、表单、组件事件、生命周期、请求、路由、组合式函数、构建 | 连接 Django 的任务页，含加载、错误、表单与 CSRF 联调 |
| Django | 项目与路由、视图、模型迁移、查询、校验、权限、事务、测试、CSRF、发布检查 | SQLite 任务 JSON 接口，含 6 项测试及强制 CSRF 验证 |

课程说明以简体中文编写，每课包含核心说明、代码、接入位置、预期结果、易错点、小练习、自检和笔记。区分「独立脚本」「项目片段」「终端命令」；代码可以复制或下载，页面不运行代码。

三个项目以任务清单为共同主题，Python 脚本可以独立完成；Django 与 Vue 项目可以按步骤连接。项目材料包含 README 和源文件，在浏览器内生成 ZIP，无压缩库、CDN 或网络打包依赖。材料中的目录结构会保留，空的 Python 包文件也会保留。

Django 教学接口只面向本机单用户演示，未实现账号与对象权限，不能直接作为公网多用户服务；正式项目需要按权限课程补齐相应规则。Vue 项目使用官方脚手架创建 JavaScript 工程，再放入下载的对应文件；材料中没有固定脚手架依赖版本或提交构建产物。

## 版本与官方来源

- Python 示例采用 3.12 语法与标准库，运行前核对本机解释器。
- Vue 采用 Vue 3 的 `script setup` 与组合式 API；Node.js 应满足当前官方脚手架要求。
- Django 示例采用仍受支持的 5.2 LTS 系列，依赖范围为 `Django>=5.2,<5.3`，安装该系列最新补丁，不把它描述为最新主版本。
- 各课和项目附官方资料链接，核对日期为 2026-11-11。外部入口标注「需联网」；示例与练习由本站编写。

## 导航、布局与记录

- `#home` 或无锚点：三条学习路线。
- `#track=python`、`#track=vue`、`#track=django`：路线准备与课程列表。
- `#lesson=py-values`：单课深链接，支持上一课、下一课及配套项目。
- `#projects`：实操项目；`#project=python-cli`、`#project=django-api`、`#project=vue-client`：材料、步骤和验收。
- 搜索支持多个关键词，检索课程名称、说明和代码；课程列表支持待学习／已学习筛选。在课程详情搜索时进入当前路线，在项目中搜索时进入全部课程。
- `/` 聚焦搜索，搜索框中 `Escape` 清空；浏览器前进后退可用。宽屏显示侧栏，竖屏使用路线选择器保留正文宽度；沿用全站明暗主题。

独立存储键 `personal_coding_v1` 保存课程与项目完成标记、自检答案、笔记（每项最多 2000 字）和上次课程，不修改英文、命令或 AI 档案。完成标记由用户决定，自检不会自动替用户标记。未知 ID 和损坏内容按结构清理；存储不可用时说明本次会话仍可继续使用。

页面、课程、代码与 ZIP 下载可离线使用；首次安装解释器、脚手架、依赖或查阅外部资料需联网。下载后运行项目需本机开发环境，不是双击课程页便自动启动服务。不同浏览器、地址、端口或设备之间不自动同步记录；本地文件存储取决于浏览器策略。

## 文件与检查

- `coding-data.js`：三条路线、课程、自检、关联、官方资料和完整项目文件的唯一内容源，代码以行数组保存。
- `coding-core.js`：路由、搜索、档案校验、UTF-8 ZIP 打包。
- `coding-app.js`、`coding.css`：阅读、自检、记录、复制、下载和桌面布局。
- `test/test-coding.js`：结构、稳定 ID、内容关联、代码类型、路由、搜索、记录隔离和打包约束。

在仓库根目录运行：

```sh
node personal-learning/coding/test/test-coding.js
node personal-learning/test/test-structure.js
node personal-learning/test/test-theme.js
```

修改示例后，还需实际运行独立 Python 示例、Python 项目测试、Django 项目测试与 Vue 构建，并验证浏览器前后端联调。项目解压和运行应在独立练习目录进行，避免写入当前仓库数据库或覆盖已有项目。
