# AI 学习 · 开发提示词与工具

入口：[开发提示词](index.html#prompts)。默认展示 **7 类、36 个开发提示词模板**，按需求与方案、产品设计、前端开发、后端开发、Bug 排查、运营与维护、二次开发编排。

## 直接用在开发中

每个模板都有适用任务、背景填写项、完整提示词、交付结果、验收提示与两条可复制的追问。输入框里的示例只作提示，未填写的内容以「待填」标记呈现，避免把示例当作真实项目情况。

- 分类与多个关键词组合搜索，可直接复制原模板，也可进入模板填写项目背景、技术栈、材料或文件位置、目标与约束。
- 填写项自动生成完整正文。正文支持直接编辑；已手动编辑的正文会被保留，点击「更新提示词」或「恢复模板正文」才按当前填写项重新生成。恢复正文保留背景填写项。
- 通用协作约定可选，包含依据实际材料、区分事实与推断、采用最小方案、如实记录验证结果。
- 收藏常用模板，在「我的收藏」中筛选；「继续上次填写」返回上次模板。
- 宽屏以分类侧栏、任务分组和填写／正文双栏组织；竖屏隐藏侧栏、折叠可选填写项，优先展示可复制正文。页面沿用系统明暗主题。

主要覆盖：需求澄清、PRD、任务拆解、验收、变更影响；流程与页面设计、原型、体验检查、文案；页面实现、接口联调、布局修复、组件与性能；接口设计、业务实现、迁移、异步任务、权限；复现、根因、前后端 Bug 与回归；发布、故障、资源、备份、运营数据、公告；项目阅读、功能扩展、外部集成、依赖升级与遗留改造。

## 按需查阅的内容

- **基础知识默认折叠**：原 6 个阶段、24 个概念、24 道自检题及 6 个阶段小练习保留；从基础知识展开学习路线与目录。旧概念 ID、深链接、笔记与进度兼容。
- **材料实操**：保留 9 个任务和虚构练习材料，提供下载、可编辑提示词、检查表、参考思路和记录。本地模型与工作流收进「进阶选学」。工单练习可检查固定 JSON 的字段、编号、分类和原文证据；检查通过不会自动标记完成。
- **大模型**：8 个模型家族，GPT、Claude、Gemini、DeepSeek、Qwen、Llama、GLM、豆包，介绍用途、入口与使用条件。
- **工具指南**：13 个工具，ChatGPT、Claude、Gemini、Codex、Claude Code、Cursor、GitHub Copilot、NotebookLM / Gemini Notebook、Perplexity、Ollama、LM Studio、Dify、n8n；工作流工具默认折叠为进阶选学。直接搜索或按工作流分类可展开查找。

模型工具资料的核对日期为 2026-11-11，官方来源保留在对应页面，具体版本、功能、区域、额度与价格以实际账号及官方说明为准。原概念资料的查阅日期仍为 `ai-data.js` 中的 2026-11-02。

## 导航与深链接

- 无锚点时进入开发提示词；`#prompts` 查看全部模板。
- `#category=frontend` 查看前端分类；`#prompt=repo-onboard` 直接打开项目阅读模板。
- `/` 聚焦当前分区的搜索；搜索框中 `Escape` 清空。在模板详情搜索进入提示词库。
- 保留 `#route`、`#concepts`、`#lesson=rag` 等原基础入口。
- 保留 `#practice`、`#lab=ticket-json`、`#models`、`#model=qwen`、`#tools`、`#tool=ollama`。
- 支持浏览器前进后退；内容跳转退出搜索，分类与收藏可组合筛选。

## 离线与本机记录

页面、模板、模型工具介绍、填写编辑、复制、材料下载与固定 JSON 检查均可离线使用。官方入口与资料链接标注「需联网」。页面提供可带走的提示词和材料，不自动调用模型、执行练习代码或发送输入内容。

各档案独立保存：

| 本机存储键 | 内容 |
| --- | --- |
| `personal_ai_prompts_v1` | 模板收藏、背景填写项、手动编辑正文、协作约定选项和上次模板 |
| `personal_ai_v1` | 原概念完成标记、自检选项、笔记、上次概念，结构不变 |
| `personal_ai_practice_v1` | 原实操完成标记、检查表、笔记、提示词草稿、输出与上次任务 |

提示词每项背景最多 4000 字，手动正文最多 28000 字。只保留现有模板及字段，损坏或未知数据按结构清理。存储不可用时显示提示，本次会话仍可使用。不同浏览器、域名、端口、设备之间不自动同步；双击本地文件时，保存行为取决于浏览器的本地文件存储策略。

## 文件与检查

- `ai-prompts-data.js`：分类、模板、填写项、正文、验收提示与追问，正文按段落数组维护。
- `ai-prompts-core.js`：路由、组合搜索、占位符替换与独立记录校验。
- `ai-prompts-ui.js`：任务列表、背景填写、正文编辑、复制与收藏。
- `ai-data.js`、`ai-state.js`：原基础课程与档案校验，稳定 ID 不变。
- `ai-practice-data.js`、`ai-practice-core.js`、`ai-practice-ui.js`：模型工具、材料实操、结果检查与实操记录。
- `ai-app.js`、`ai.css`：共享导航、折叠基础目录、搜索和桌面布局。
- `test/test-ai.js`：原课程与档案验证，并调用 `test/test-practice.js` 与 `test/test-prompts.js` 验证资料结构、引用、路由、模板拼接和独立记录。

在仓库根目录运行：

```sh
node personal-learning/ai/test/test-ai.js
node personal-learning/test/test-structure.js
node personal-learning/test/test-theme.js
```

新增字段先补结构校验；更新范围或数量时同步更新本说明、个人学习 README、总首页与仓库 README。
