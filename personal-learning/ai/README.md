# AI 学习 · 基础篇

入口：[AI 学习](index.html)。6 个阶段、24 个基础概念、24 道自检题与 6 个纸面小练习。沿用个人学习系统的导航、明暗主题及阅读优先排版。

| 阶段 | 目标 |
| --- | --- |
| 认识 AI 的边界 | 分清 AI、机器学习、深度学习与生成式 AI |
| 模型如何学习 | 理解模型与参数、训练与推理、数据划分、泛化 |
| 理解大语言模型 | 认识 LLM、词元、上下文窗口和 Transformer |
| 提问与验证 | 写清任务，区分结构正确、事实正确与评估结果 |
| 用知识增强回答 | 区分嵌入、检索、RAG 与微调 |
| 从模型走向应用 | 理解工具调用、工作流、智能体与人工复核 |

每个概念包含核心解释、原创场景例子、易混淆点、自检与可追溯的参考资料。练习可在笔记或纸上完成，不调用模型服务，不需要 API 密钥。资料查阅日期为 2026-11-02；实现与课程内容分开存放，便于继续扩充。

## 使用

- 首次进入查看六阶段路线，点击「开始学习」或任意概念开始阅读。
- 使用概念搜索、学习状态筛选和目录跳转；`/` 聚焦搜索，搜索框中 `Escape` 清空搜索。
- 自检选择答案后点击「检查答案」，会展示解释，可重新尝试。
- 「标记为已学习」是自己的学习记录，与自检结果分开；可取消标记。
- 每个概念可保存最多 2000 字的本机笔记。继续学习会优先回到上次未完成的概念。
- `#route`、`#concepts`、`#lesson=rag` 等地址可直接打开相应视图；URL 变化支持浏览器前进与后退。

## 阅读与保存

桌面左侧目录常驻；宽屏将概念正文和自检笔记并排，竖屏改为单列依次阅读。正文约 17px、核心定义约 18px、行距约 1.9，并限制长文行宽。搜索栏随阅读滚动固定，窄窗口保留基本兼容。

档案使用独立存储键 `personal_ai_v1`，包含 `completed`、`answers`、`notes` 与 `lastLesson`。记录仅保存在当前浏览器，不跨设备同步，也不写入英文模块。浏览器拒绝保存时会提示，当前页面的内存记录仍可使用。

## 文件与检查

- `ai-data.js`：阶段、概念、问题、练习与来源；稳定概念 ID 用于关联进度。
- `ai-state.js`：档案校验与长度限制。
- `ai-app.js`：路由、筛选、自检、笔记与界面。
- `ai.css`：桌面与阅读样式。

```sh
node test/test-ai.js
```

来源包括 Google 的机器学习课程、Hugging Face 教程，以及 AWS、Anthropic、Google Cloud、LangChain 官方文档。每条来源在概念页可直接访问；自检与练习为本站编写，不代表这些机构的认证考试。
