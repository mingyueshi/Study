# 开发命令

六个常用开发工具的命令速查与自测页：macOS、Linux 与 Shell、Git、pyenv 与 pip、nvm 与 npm、vi 编辑器。查得到、复制得快，再用遮住自测和掌握标记把命令记进手里。入口页是 [dev/index.html](index.html)。

## 使用

- 侧栏是工具目录，每项带「已掌握/总数」计数；顶部进度条统计全部命令。
- 工具页按使用场景分组展示命令卡：命令本体（点击复制）、说明、示例（点击复制）和补充提示，危险操作用 ⚠️ 开头。
- 搜索框支持命令、说明、示例的关键词匹配，跨全部工具返回结果；任意时刻按 `/` 聚焦搜索，Esc 清空。
- 「遮住自测」把命令文本打码：先看描述猜命令，点击揭晓核对。揭晓只在本次会话有效。
- 「标记掌握」逐条记录学习进度；「继续」按钮回到上次使用的工具。
- 深链接 `#tool=git` 直接进入对应工具。

## 保存位置

进度保存在浏览器的 `personal_dev_v1` 键下，只存已掌握命令的 id 和上次工具，不与其他学习方向的档案混用。不同浏览器、域名或端口之间不自动同步；直接双击本地文件打开时也能使用，只是记录跟随该文件。

## 文件与检查

- `dev-data.js` 命令数据：工具 → 分组 → 命令（id、cmd、desc、example、note），纯数据不掺逻辑。
- `dev-state.js` 本机记录的读取与校验：脏数据一律丢弃。
- `dev-app.js` 渲染与交互：hash 路由、搜索、复制、遮住自测、掌握标记。
- `dev.css` 模块样式：每个工具一组专属色。
- `test/test-dev.js` 数据结构与存储校验。

在本目录运行：

```sh
node test/test-dev.js
```

添加命令时在 `dev-data.js` 对应分组里加一条，id 保持全模块唯一，说明文字用中文标点。
