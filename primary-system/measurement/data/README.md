# 单位与测量内容

`topics.json` 保存单位、换算关系、生活参照、例题和动手活动。专题入口为
`/measurement/`，五类换算页分别使用 `length`、`area`、`volume`、`mass`、
`time`，生活估算页为 `estimation`。保留已发布的页面、题目和情境 ID，
以便继续使用网址及锚点。

Schema 1 包含五类单位和五个估算情境。`content.py` 在加载时校验文本、
唯一 ID、引用、单位进率、换算示例答案与估算参照。每类以最小单位为基准，
每个 `factor` 等于 1 个该单位包含的基准单位数。体积和容量共用一个单位表，
允许不同名称的单位有相同进率，例如 mL 和 cm³。

每项估算的 `reference` 为 `terms` 中各项乘积之和再除以可选的 `divisor`，
并位于 `lower` 与 `upper` 之间。样本和区间用于讲解估算假设，实际任务可按
对象、工具或条件调整。相对偏差以参考值作分母，页面最多显示一位小数。

换算与估值比较由普通 GET 表单完成，无需脚本。换算按有理数精确计算，
结果保留最多 18 位小数。需舍入时用「≈」并列出精确分数。输入支持全角数字，
限制为非负十进制数，整数最多 8 位、小数最多 6 位。「交换单位」保留输入数值。
日、时、分、秒用于换算固定时长。日期间隔、跨单位类别换算和密度计算不属于换算器。

页面无模型、作答记录和写入接口。GET 参数只用于当前结果，可用网址回看。
改动后在 `primary-system/` 运行：

```sh
.venv/bin/python manage.py test measurement catalog.tests.CatalogTests --noinput
```
