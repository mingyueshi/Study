# 数学公式数据维护说明

`formulas.json` 是数学公式专题的全部内容（Git 跟踪、手工维护），加载与校验在
`mathformulas/content.py::load_data()`。无模型、无迁移，页面 GET 不写学习记录、
不创建游客会话。修改内容后运行 `.venv/bin/python manage.py test mathformulas`。

## 结构

- `schema_version: 2`；`stages` 固定依次为 `primary`（小学）、`junior`（初中）、`senior`（高中）。`wip: true` 显示「整理中」。
- `chapters` 按学段归属，`code` 唯一，顺序即章节导航顺序；`emoji`、`title`、`intro` 描述章节。
- `groups` 为 `{chapter, title, items: [...], note?}`，`note` 可省略。
- 每条 `items` 为 `{id, name, formula, usage, example: {question, solution}}`：稳定 ID、名称、公式、什么时候用、小例题和讲解。
- ID 使用小写字母、数字、连字符，全库唯一。现有 ID 已分配并保存，重排公式或修改文字时保留原 ID，新增内容另取未使用的 ID，不按新位置重编号。收藏和 `#formula-<ID>` 深链接都依靠它关联。

## 文本与规模契约

值内禁英文双引号、裸换行、HTML 标签；行文用中文标点。公式用 Unicode 纯文本，
如 `²`、`³`、`√`、`π`、`±`、`ₙ`，不引入 LaTeX、CDN 或外部字体。
名称最多 30 字、公式 140 字、使用场景 120 字、例题 180 字、解答 240 字、组标题
40 字、note 160 字、章节 intro 100 字。每条内容必须有使用场景、例题和解答。

当前 20 章、58 组、196 条，均配一例：小学 10 章、42 组、157 条；初中 5 章、
9 组、23 条；高中 5 章、7 组、16 条。规模下限仍为小学至少 8 章、36 组、150 条，
初高中各至少 4 组。新增时同步更新 README、规模测试和此说明。

## 内容准确性

讲清什么时候用、题目的条件和单位，再示范代入或推理。公式和知识法则都配具体
例题；不把「有一条公式」等同于「所有情况都适用」。例如概率计数要求各结果等
可能，平行四边形和三角形使用对应高，圆柱表面积分清是否包含两个底面。
利息、税额例题只按题目给定的简化条件运算。修正公式时在 `VALIDATION.md` 记录。

## 搜索和本机收藏

`?stage=`、`?chapter=` 保留原分章入口；`?q=面积` 跨全部学段、章节搜索名称、公式、
使用场景和例题，多个空格分开的关键词须同时命中。服务端可直接渲染搜索结果，
无脚本仍可搜索、阅读例题和打开公式出处。前端即时筛选同一份内容，零结果显示 0 条。
`?view=favorites` 为本机收藏视图，可以与关键词组合，清除关键词仍留在收藏夹。

收藏只存当前浏览器 `localStorage`，按学习账号或游客分别保存稳定 ID，不入库、
不跨浏览器同步，清理浏览器数据会清空。支持跨标签页更新；存储不可用时保留本页
临时选择并明确提示，搜索和例题仍可用。侧栏复用平台 `sidebar-layout.js`：默认右侧，
可换边并记住位置，窄屏可展开。
