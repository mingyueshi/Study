# 飞花令诗句与优先版本

飞花令从当前就绪版的古诗文数据生成派生索引。练习范围包括全唐诗、宋词（含宋词三百首）、诗经、楚辞和千家诗；不收录论语、百家姓、千字文、三字经等非本玩法诗词范围。选集重叠不能视作唯一作品数，页面以去重后的完整诗句计数。

## 令字

- 预置令字 29 个（花月春山水风雪云雨江日天秋酒夜柳桥马竹红白青海河梅灯舟松荷），索引为其预计算 `uses/hint_pool`，页面 chips 按可用句数标注、不足五句自动禁用。
- **自定义令字**：预置之外的任意单个汉字都可开令，走运行时句文本检索（`instr`），阻塞粒度为整句键；语料不足五句时后端如实拒绝（503）。自定义令字同样不写学习记录。
- 全部可读句入索引（不再按预置令字过滤）；预置与自定义的差别只在检索路径，不在可作答范围。

## 句界和字形

- 以原段中的句号、问号、叹号为句界；逗号、顿号和分号保留在句内。不跨原段补句。没有句终符但带逗号、末尾为汉字的结构化对句可保留；悬挂标点、夹注及非正文符号按规则排除。
- 输入完整句或其中含令字的完整分句均可。输入本身必须含令字，答中与揭晓都展示完整句；该句所有含令字分句同时标用。
- 固定 `opencc-python-reimplemented==0.1.7` 的 `t2s` 规范化繁简，除常用标点和空白外按精确文本键查找。不用谐音、模糊匹配或任意替换。未命中只称“暂未收录”。
- 自动筛选不等于逐句教学审校，也不代表统一的教材版本。诗单可打开实际来源详情；来源未署名时如实标注。

## 优先版本清单

`feihualing.json` 保留 29 首熟悉版本，供题名、署名、已核对的少量异体和提示优先选择。它不限制可作答诗句的总量。来源用 `version + path + locator` 定位，校验 SHA256 和原段；不写本机主键，不靠题名猜换来源。原数据库文字保持原样。

《晓出净慈寺送林子方》的显示采用教学常用题名与杨万里署名，千家诗来源仍保留《西湖》与苏轼的异署传统；具体说明及文献见条目的 `editorial_note`、`editorial_sources`。不可把这种定点覆盖当作其他作品已完成校对。

调整优先版本时，先核对原诗、作者、路径、定位和每段原文，保持展示与来源字形对应。新增公开诗词仍走资料库导入流程，索引从就绪版数据重建；不在清单中逐首复制完整诗库。

## 本地派生索引

在 `primary-system/` 执行 `.venv/bin/python manage.py build_feihualing_index` 可显式重建。索引缺失、损坏或来源配置改变时也会自动重建。文件在 Git 忽略的 `.feihualing-cache/`，按当前数据库身份隔离，不随基础包导出。该命令只读取诗词所需列，释放主库后转换，写临时索引、校验并原子替换；不复制或改写正式数据库。

正常请求只用索引检索、核对就绪版和来源；提交、提示与已有诗单引用的诗句仍现场核对原段。索引内容变化时需重新开局。游戏不写学习、掌握或账号历史。
