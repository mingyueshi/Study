# 人类起源专题数据

`stations.json` 按顺序编排五个学习站。正文、线索、图注、判断题和出处随代码发布。Django 读取文件并渲染页面。访客可阅读和作答，展开答案时直接显示解释。

- `slug` 用于站点地址，发布后保持稳定。
- `figures` 引用项目内的静态素材。展品翻模、复原展示和教学示意图分别标明，`source` 使用本篇资料列表从 1 开始的序号。
- `clues` 通常每站三条，中国遗址站五条，分别写观察和解释。判断题每站三个选项，每项都写反馈，仅一个选项的 `correct` 为 `true`。
- 家谱站的 `timeline.bars` 用同一条时间轴，从约 400 万年前到今天。每条的起点和终点填 0 到 100 的百分比，正文年代使用约数。
- 家谱站的 `comparison.cards` 用 `group` 引用迁徙图的七个人群稳定 ID，名称、颜色、记录时段与消失说明均由视图复用，不另存一份年代。`evidence` 与 `observation` 分别说明留下什么证据、怎样比较；`marker` 与 `year` 打开对应点位及有代表记录的年代。近 40 万年放大时间条与可展开人群卡按单列编排；较早的总览时间条用可选 `group` 复用颜色。
- `comparison.figure` 与线索的可选 `figure` 使用与主图相同的结构，新增 `observation.prompt`、`observation.answer` 编排观察问题与展开解释。本轮加入英国自然历史博物馆的头骨侧面对照，以及史密森尼的戈纳切痕骨骼、受热燧石三张本地实物图。图注只描述照片可见的部位；原件照片、翻模与示意图保留各自标注。
- 所有学习站图片支持本地大图对话框，可用关闭按钮或 Esc 返回；关闭脚本时链接仍直接打开原图。`resources` 的 `title`、`prompt`、`source` 编排中文选学引导，URL 从本站出处列表解析；外部三维与博物馆原文明确标注「需联网」并在新页打开，正文图片不依赖外部服务。新结构与交叉引用由 `humanorigins/tests.py` 校验。
- 中国遗址站复用诗词地图的示意底图，介绍元谋、北京人、田园洞人、白石崖和哈尔滨头骨五组发现。线索的 `id`、`anchor` 保持稳定，前三条沿用 `clue-1` 至 `clue-3`；`order` 只调整展示顺序，不改变旧深链接。`site_map` 维护地图标题、替代文字与年代边界说明；`map_pins.sites` 用稳定 ID 关联图上百分比坐标，北京人和田园洞使用相邻的两个可点击编号。地图与五组实物线索上下排列。
- 迁徙图底图使用 Natural Earth 1:110m 陆地数据，箭头为教学示意。阅读所需图片都在项目内，资料原文链接需联网。
- 迁徙站的 `atlas` 编排年代地图：`steps` 为 17 个从早到晚的阅读节点，`regions` 为 8 个地区的代表证据，`groups` 为 7 类古人类的生活记录与消失说明。`years_ago` 是距今年数，0 表示今天；地区节点是「已有证据」的教学约数，不能解释为首次到达或连续居住。年代滑块各格并非等长时间。
- 每个年代的 `focus_region` 指定自动演示选中的地区，`events` 编排该年代的发现，并通过 `group` 和 `source` 引用人群与资料。`playback` 维护播放文案、状态用语和每站 3／6／10 秒的速度选项，默认 6 秒。新字段由 `humanorigins/tests.py` 校验。
- 自动播放从当前节点继续；停在今天时从非洲重新开始，播放至今天自动停止。手动选年代、选地区、打开出处、切换浏览器历史、隐藏页面或离开时暂停；旧计时回调不会推动新的播放。速度只影响阅读停留时间，不代表历史时间按比例流动。
- 年代观察窗同步展示本年代发现，以及所选地区曾出现过的人群在代表记录中的状态。共用人群时段不能推断每个地区的连续居住；晚于已知记录时标注灭绝时间未定，只有具有约略消失年代的记录使用消失状态。各尺寸窗口统一将年代说明放在地图下方，正文内部保持单列且不设置说明区内部滚动。学习站导航位于正文外的侧栏，默认右侧，可左右切换；宽屏可以折叠，使用 `humanorigins_navigation_collapsed_v1` 保存折叠状态。小于 900 像素时导航位于上方并默认收起。
- 地区的 `groups` 引用人群稳定 ID，`sources` 引用本站资料序号。人群的 `oldest`、`youngest` 用于近 40 万年的共同刻度，直立人更早的部分裁切显示。`status` 分为 `living`（仍存在）、`approximate`（约略消失时间）与 `unknown`（灭绝时间未定）；最后化石年代不当作确切灭绝日期。
- `groups.color` 为 7 类人群指定不同颜色，图例、点位和说明使用同色，同时保留名称与问号以区分状态。`map_markers` 维护 17 个代表点位，其中 8 个为各地智人线索，另外 9 个为其他古人类的分布或遗址记录。`x`、`y` 是地理位置，`label_x`、`label_y` 是避让后的标签位置，二者以连线连接。
- 点位的 `oldest`、`youngest`、`status` 描述该处选用的代表记录，不能套用人群整体的生活时段。例如周口店与昂栋分别显示直立人的当地记录。记录开始前隐藏；具有约略消失年代的点位在该年代及之后退场；灭绝时间未知者保留空心问号，并列入独立清单。`last` 表示末段线索，仍不能当作灭绝时刻；`unknown` 不表示当时仍有该人群居住。
- 点击点位或不确定记录清单会暂停播放，显示该处记录、年代与出处；`marker=denisovans-baishiya` 等参数保留所选点位。隐藏或退场的点位不保留选中状态，自动播放会重新跟随演示地区。关闭脚本显示全部代表记录，并保留地区与人群卡片链接。
- 点选详情紧接地图下方，主动点击时定位到详情并转移键盘焦点，提供「回到刚才的地图点位」；恢复深链接和自动播放不抢焦点。今天的未知结尾标注「已消失 · 年代未定」，更早年代仍表达记录之后情况未明，不把未知结尾画成继续生存的证据。
- `routes` 用地区 ID 连接，`via` 为底图百分比坐标；跨越地图左右边缘时分段绘制。路线只表示扩散方向，不能据此判断具体路径或人群相遇。`world-land.svg` 沿用原迁徙图的本地陆地底图，不请求外部地图服务。
- `/human-origins/migration/?year=45000&region=europe#migration-atlas` 可直接打开约 4.5 万年前的欧洲记录；不合法的年代或地区恢复默认值。关闭脚本仍能阅读全部地区和人群记录，地区锚点保持可用。交互脚本为 `static/humanorigins/migration.js`。


- 白石崖与哈尔滨线索用 `group`、`marker`、`year` 关联家谱和年代地图；迁徙点位的可选 `site` 反向引用中国遗址稳定 ID，家谱人群卡由同一份中国遗址数据生成实物入口。`supplementary_sources` 补充独立证据出处。
- 哈尔滨点位的 `record_type=minimum_age` 表示单件头骨的年代下限，`oldest` 与 `youngest` 均为 146000。仅在这个阅读节点标为「单件化石 · 年代下限」，更晚节点标记录之后情况未明，今天标已消失但年代未定；更早节点未亮起也不代表当时无人。它不是居住区间，不能用于绘制白石崖至哈尔滨的迁徙路线。白石崖下颌骨与晚期肋骨的年代分别说明，不合成同一件标本。
- 新增本地实物图：`xiahe-mandible.jpg` 来自马普演化人类学研究所的夏河下颌骨新闻资料，`harbin-cranium.jpg` 来自英国自然历史博物馆的 2021 年头骨照片。哈尔滨人群归属与分子证据采用中科院古脊椎所 2025 年研究，图片旧资料不作为最新归属依据。

修改后，在 `primary-system/` 运行 `.venv/bin/python manage.py test humanorigins`。
