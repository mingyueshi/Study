# 数学思维训练营

入口 `/mathcamp/`，学习广场「数学」区注册；五条路线各三种方法、三关训练，
共 15 个方法示例、15 关和 45 条渐进提示。零模型只读应用，不增加数据库表、
游客会话、账号学习记录或积分；巧算独立成线，并链接原有奥数挑战。

## 内容与 schema 1

`camp.json` 为方法、题设、模型配置、提示、参考答案和出处的唯一来源。
`content.py::validate` 先验证结构，再用 `puzzles.py` 的独立求解器核对数据。

- 路线稳定 ID 为 `logic`、`sudoku`、`magic`、`patterns`、`mental`。
- 每条路线有前置基础、三种方法（使用时机、例子、步骤）、三个好习惯、迁移问题及 HTTPS 出处。
- 每关有唯一稳定 `id`、1～3 的 `level`、`kind`、标题、目标、题干、`puzzle`、至少三条提示、答案与解释、复盘问题。
- `#methods`、`#habits`、`#drill-<ID>`、`#transfer`、`#sources` 可直接定位。重排或改文案时保留题目 ID；若题意与答案实质改变，应换新 ID，避免旧完成标记指向新题。
- 中文正文不含 HTML、裸换行或英文双引号；题目中的数字、空格、数值范围与解都按整数校验，布尔值不作为整数接受。

| 训练 | 配置与判定 |
|---|---|
| 逻辑推理 | 三至五项一一匹配；结构化 `eq`／`ne`／`before`／`next`／`apart` 线索同时用于求解与前端检查；出版校验必须恰有一解 |
| 数独 | 固定 4×4（2×2 宫）、6×6（2×3 宫）、9×9（3×3 宫），分别有 8／20／45 个空格；题设固定，行、列、宫各含 1～n 一次；独立回溯校验唯一解 |
| 幻方 | 三阶补三格、三阶从中心推理、四阶修复；1～n² 各一次，题设不变，行、列和两条主对角线同和；接受所有合法摆法，不强制逐格等于参考解，也不声明唯一解 |
| 找规律 | 固定差、等差差值、奇偶位置交错三类；用声明模型核对已知项与后两项；明确有限数据通常不决定唯一后续，自动检查仅接受本题约定模型 |
| 巧算速算 | 凑整相加、提公因数、连续整数首尾配对；参数计算与存储答案交叉校验，不执行字符串算式或动态代码 |

题目在发布时固定，不在请求中随机生成。数独在编排时从合法棋盘移除数字，
每次删除后验证唯一性；发布后以文件中题设为准。唯一解不代表只能用一种推理方法，
也没有把大小或空格数当作客观难度评级。

## 页面与互动

`views.py` 仅 GET／HEAD，继承平台主题、字号和宽屏外壳；路线侧栏默认右侧，
换边由公共 `sidebar-layout.js` 保存。`engine.js` 是纯规则，`camp.js` 处理控件。
无运行时外部请求、自动播放或计时；关闭脚本可在纸上训练，逐条展开原生提示与答案。

填写与完成是两回事。检查会标出冲突及尚未填写的项；数独无直接重复的半成品
不判完成，也不宣称一定有后续解。幻方单独列出行、列与两条对角线的和。
候选数取当前行、列、宫允许集合的交集，不冒充最终答案；全角数字可输入，
小数、指数、越界数与混入字符被拒绝。

逐次点击只展开一条提示；查看候选数、提示或完整讲解后完成，显示「借助提示完成」。
未用这些帮助完成则显示「自主完成」。重填不会撤销本页已经使用帮助的状态，
也不会降低已有自主完成标记。标记用于本机自我复盘，不是服务端成绩证明。

## 本机完成标记

键为 `primary-math-camp-progress-v1:<user-ID|guest>`；只保存题目 ID 到
`independent`／`assisted` 的映射，账号与游客分开。首页汇总五条路线与 15 关；
页面禁缓存，避免把账号作用域的 HTML 共享给其他访问者。不保存未完成输入草稿。

只接受当前题目 ID 与两种合法状态，忽略损坏内容、旧 ID 和未知值；保存前合并
其他标签页结果，自主完成优先。通过 `storage` 事件更新其他页面；读取或写入
不可用时明确提示，仍能练习与检查，完成标记最多暂存本页。没有删除其他模块的数据。

## 维护与验证

修改结构先更新校验；修改题目后运行：

```sh
.venv/bin/python manage.py test mathcamp catalog.tests.CatalogTests --noinput
node --test scripts/test_mathcamp.cjs
make test-frontend
```

前端测试接入 `make test-frontend`，后端测试接入 Django 自动发现。
数学测试使用独立约束、反例和可替代的合法解，覆盖唯一性、宫限制、
两条对角线、缺项不完成、候选交集、输入范围和记录合并；浏览器另验实际提示、
填写、检查、刷新恢复、深链接、主题、无脚本与存储故障，不以纯函数测试代替页面验证。
