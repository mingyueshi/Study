# 《道德经》八十一章内容源

每章一个 JSON，主编辑文件为上一级的 `daodejing-01.json` 至 `daodejing-81.json`。原文、逐句译文、词义、停顿、背诵提示与题目随项目保存，不在运行时抓取或自动翻译。目录注册在 `catalog.json` 的 `daodejing` 全书下；上篇道经三十七章，下篇德经四十四章。

## 原文与解读

- 原文底本为本机简体古籍《老子》，来源路径 `poetry/simplified/诸子百家/老子.json`，版本 `01a1183cd9bbc243bb156967043c32b6685c0d2f+native`，来源文件 SHA256 为 `c4a08487b0421e1fecd626642bf0580a98671995134c3044e429387f50327893`。八十一章分别对应 `/content/0` 至 `/content/80`，篇级原句锚点保留底本整章正文。
- 统一引号为「」与『』。第七章括号中的「后其身一作退其身」是异文提示，精读正文采用前一种写法，原典锚点仍保留原始提示。其他原文用字依底本保留，不暗中换成别的版本。
- 共 428 个精读句。通常按句号、问号、叹号分句；第十八章四个并列分句依分号分别配译。原句拼接须还原底本正文，仅允许上述引号和异文提示处理。目录同时固定每章句数与有序汉字指纹。
- 译文、简短词义、阅读提示与练习为本馆编写的入门读法。理解时参考公开的古代注释 [王弼《老子道德经注》](https://zh.wikisource.org/wiki/道德經_(王弼本))，外链按章锚点定位；它与本机底本文字可能不同，不将其冒充同一版本。没有整段导入现代译注。
- 解释「道」「无为」「自然」「病」等词时结合所在句子，不给一个词在全书强套同一含义。第十一章的三个「其无」分别指向轮毂、器皿和房屋中的空处，逐句提供线索。
- 保留古代说理的内容，也说明其语境。有关无知无欲、愚之、刑罚、鬼神、长生、婴儿与虫兽等文字，给出背景或比方提示；不把古代治理观念照搬为今天的教育要求，不把理想化描写当作现实保证。

## 练习与工具

每章两道选择、一题讲述自查，共 243 道，其中选择 162 道、自查 81 道。题目指向本章有效句子；词义题回到原句，理解题核对主旨，讲述题要求用自己的话说明并找原文依据。

逐句朗读、全文朗读、语速与重复、关键词背诵、全遮与揭示、即时判题和本机标记均沿用古文馆模块。每章提供原文、讲解、练习、答案四种打印页，各句另可单独打印原文或讲解。朗读依赖设备语音，不等同于人工校核的录音。
