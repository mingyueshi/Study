# 《滕王阁序》来源与分段

教学内容只维护在上级 `tengwanggexu.json`。正文采用王勃《秋日登洪府滕王阁饯别序》，原典为《全唐文》卷一百八十一，固定到 [维基文库修订版 12697857](https://zh.wikisource.org/w/index.php?oldid=12697857&title=全唐文/卷0181)。2026 年 11 月 13 日逐段核对七段完整序文，采用正文用字，删除「一作」校记，繁体转简体、调整现代标点；𬴂采用通用字形騑，锺、馀分别写作钟、余。保留该本「层台」「遥襟甫畅」「安贫」等写法，不与其他本子拼接。读者若持其他版本，可按篇末出处核对。

`original.json` 保存整理后的七段原文及 SHA256，供测试独立核对教学分句的完整性与顺序；不作为第二份教学页面。指纹为七段含标点的 UTF-8 文本直接拼接后计算，固定为 `30ce9f53ab5df3b487aa5e73b9ec873bbedd41b8b4ba73bf966bce2663aee6fb`。不得为通过测试随意重算，改底本时必须复核原典、说明变化并更新教学内容。

七段序文为 67 个精读单元，附诗四联为 4 个单元，共 71 个单元、190 处词义／典故／指代提示。译文、句解、篇章梳理和 24 道练习由本馆自编，每段两道选择、一题讲述自查。难字注音标在词条上；设备朗读未使用校核录音，遇多音字以词条注音为准。神话与典故作为文学表达解释；「童子」「三尺」不作作者确切年龄、身高的依据。

附读《滕王阁》诗单独标出，依据已存在的本机《全唐诗》王勃《滕王阁》，保留「珮」字。原典定位为 `poetry/simplified/全唐诗/poet.tang.3000.json`、`/463`，文件版本 `b8594f81a89752241442f2ce267d6f66f96704ee+t2s017`、SHA256 `fc5be164c92f9d2b56bbc5b6529a71c3530f84d0597145e585682115b6775f86`。四联分别以原句定位，查本机原典时核对版本、路径、指纹、定位和原句；序文没有篇级本机定位，不冒用附诗原典，不新增数据库导入。
