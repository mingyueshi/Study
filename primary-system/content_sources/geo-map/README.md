# 地理图谱

统一版入口为 `/geography/atlas/china.html`。本目录保存模板、数据和配套素材。改动后运行 `make study-topics-data`。

标题、导航和筛选使用统一侧栏，默认靠右，可切换到左侧并在本浏览器保存。竖屏按地图、档案的顺序阅读。横屏且内容区够宽时，档案放在地图旁边；窄屏上，侧边栏移到内容上方。

中国与世界动物地图的选取区位于地图下方，以带照片、名称和编号的卡片展示。点照片和点地图标记会同步选中同一只动物，按栖息地筛选时，照片卡与地图一起变化。

中国植物补充北京侧柏、安徽黄山松、河南牡丹、广东木棉、西藏青稞与宁夏枸杞；世界植物补充印度榕、日本柳杉、南非帝王花、欧洲山毛榉、安第斯巨型凤梨与西澳草树。新增资料核对见 [植物资料说明](PLANT-SOURCES.md)。

两张植物地图沿用地图下方的照片卡片，不使用下拉选择。地图编号、照片和档案联动，植物深链接使用 `?plant=植物ID`。窄屏或竖屏选择植物后会展开植物档案，便于阅读；宽屏档案默认在右侧，可切换到左侧并保存偏好。地图标记只表示代表分布或栽培地点，棉花、水稻、茶树等在正文中注明栽培情况。

中国和世界地图都可以换图层、看图例、点选地点或用下拉框定位。放大后可拖动地图，或在地图获得焦点后按方向键平移。「找一找」每轮随机出 5 题，点错时可读提示，答对再进下一题。

地图用于学习方位。中国省级轮廓由 DataV 边界数据简化而来，世界轮廓来自 Natural Earth 110m，山脉和二维河道为近似示意；3D 页另用真实河道中心线和数字高程。中国图右下的小图显示南海诸岛和十段线。世界图使用等经距画法，靠近两极的陆地形状和面积会变形。

世界地图上方直接列出七大洲按钮，点击后逐洲突出轮廓并显示重点，点「全部大洲」返回全览。洲别选择也可用深链接，例如 `world.html?continent=africa#map`。切换图层或进入「找一找」时收起洲别高亮，回到七大洲自由探索后恢复。

图谱页面保留侧边导航，动物地图保留页头的地图切换入口。各页 hero 按主题配色，地图、档案、观察问题和目录用背景与边框区分。

## 数据与页面

- `content.js`、`map-data.js` 和 `world-data.js` 分别维护图层元数据、中国档案和世界档案。省份 `facts` 每条记录有五个要点。世界国家与地区用地图几何中的英文名作 ID，其余地点继续用现有 ID，例如 `p110000`、`f20`、`n2`、`wf2`、`o1`。
- `world-data.js` 的 `GM_CONTINENTS` 同时维护洲别档案。每洲有 `location`、三条 `facts`（标题与正文）、`observe`、`places`（代表地点 ID）和 `source`。跨洲国家沿用本图既有的大洲映射。
- `atlas.js` 从已有档案生成地点索引，供目录、路线、图层定位、关联档案和练习共用。新增地点时保留原档案的 ID 规则，并在对应 SVG 中用 `data-id` 注册可点选的图形。原 ID 会出现在已有链接里。
- `atlas-data.js` 用地点 ID 组织路线和双向关联。每个路线站点填写一条观察提示。中国的邻居还会按中文名关联到世界地图中的对应记录。中外对照卡在 `map-data.js` 的 `GM_WORLD_TEASERS` 中维护，`places` 依次引用左右两个地点。
- `media-data.js` 用地点 ID 挂接素材，`media.js` 在地图档案、省域站和图册复用渲染。图册支持 `?place=地点ID`，例如 `gallery.html?place=f20`。素材保留来源页、作者和适用的授权链接。图片按原画面等比缩放，转成 JPEG 后保存在 `assets/`，影片只打开央视网。
- `shared.js` 提供投影、SVG 路径、世界底图和省域站卡片。中国与世界地图页各自绘制图层，由 `map-ui.js` 处理定位、图层切换、档案关联、缩放和练习。目录和路线页只加载档案数据。
- `animals-data.js`、`world-animals-data.js` 分别维护中国和世界的动物档案与栖息地图例，交互共用 `animals-app.js`。动物 ID 用于直达链接和 `assets/animals/` 下的同名 JPEG 照片。中国档案用 `adcode` 关联省域站，世界档案用 `mapPlace` 关联国家、地区或大洋。点位只标出代表栖息地。档案里的 `source` 是资料出处，照片来自另一页面时填写 `photoSource`。
- 动物与植物地图共用 `animals-learning.js`，提供关键词与观察状态组合筛选、随机认识未观察的动物或植物、上一种／下一种浏览和两种五题练习（看照片、读线索）。练习复用档案的 `clue` 与本地照片，按当前筛选抽题，答题后查看地点与线索，可重练本轮错题。观察需主动标记，可取消；中国动物、世界动物、中国植物、世界植物四张地图分开保存在当前浏览器，不随账户同步。存储受限时保留本次操作并显示提示。练习不自动计入观察，刷新后重新开一轮。植物搜索还覆盖学名和环境适应说明，提示使用对应的生长环境。回归测试为 `scripts/test_animals_learning.cjs`。
- `plants-data.js`、`world-plants-data.js` 维护植物档案，复用 `animals-app.js` 和 `animals.css` 的地图、筛选和照片交互。字段包括稳定 `id`、中文名 `name`、学名 `scientificName`、生境 `habitat`、代表地点 `place` 与经纬度 `point`，以及分布 `home`、适应方式 `adaptation`、观察线索 `clue`。中国用 `adcode`、世界用 `mapPlace` 关联原地图；`source` 链接植物智或邱园等资料，`photoSource` 链接照片来源页。本地 JPEG 保存在 `assets/plants/`，无需运行时联网。新增或改动字段时同步更新 `test/test-geo-map.js` 的结构与引用校验。
- 地图链接用 `?place=地点ID#map`，例如 `china.html?place=f20#map`，自动选中对应地点和图层。需要保留路线时加上 `&route=路线ID`。同一地点也可以在另一可见图层打开，例如 `world.html?place=China&layer=home#map`。

动物照片按原比例缩放并压缩为 JPEG。大熊猫照片由 J. Patrick Fischer 拍摄，采用 [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) 许可。褐马鸡照片由 Somongkol Teng 拍摄，采用 [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/) 许可。原图及其他照片的出处见页面档案。

`china-geo.js` 和 `world-geo.js` 由脚本生成。重新生成时可传入本地源文件，省略参数时脚本会尝试联网下载。打开学习页面只读取本目录的文件。

```sh
python3 content_sources/geo-map/scripts/build-geo.py <100000_full.json 路径>
python3 content_sources/geo-map/scripts/build-world.py <countries-110m.json 路径>
node content_sources/test/test-geo-map.js
```

## 3D 中国地图

`china-3d.html` 由地图首页、中国地图和专题导航进入；省域站也可带原省份 ID 返回立体地图。地址支持 `?place=p710000`，兼容 `?adcode=710000`。点选会更新地址，刷新仍显示该省份；无效参数提示重新选择。地形定位也支持深链接，例如 `?landform=f9` 直达青藏高原；`?river=f20` 定位长江并查看原档案。旋转、缩放、标签显隐和高度倍率只调整视图，不写学习记录。

省名默认显示，使用浅底大字标签，可直接点省名打开档案；密集处用引线避让，空间不足时可放大或从省份列表选择。省界使用固定像素宽度的深线与浅色衬边，选中省份显示橙色粗边。「省份分色」用不同颜色区分相邻省份，仍保留地形起伏，颜色不代表海拔。

`china-3d-data.js` 维护观察任务、海拔色阶、省份配色、高度倍率、地形标签和分类定位目录，结构由 `test/test-geo-map.js` 校验。正文复用 `map-data.js`，省界与南海小图复用 `china-geo.js`，不复制省份档案或修改原地点 ID。`china-terrain-data.js` 是由公开 DEM 生成的本地真实高程网格，包含 447599 个顶点和 843942 个三角形。选中省份只高亮颜色与边界，不抬高模型；切换配色、显示倍率均不改变原海拔。高程来源、精度与重建步骤见 [真实地形数据说明](TERRAIN-SOURCES.md)。3D 渲染采用本地 Three.js 0.180.0 与 OrbitControls（MIT），来源为官方 npm 包，许可见 `assets/vendor/THREE-LICENSE.txt`，技术资料见 [Three.js 官方文档](https://threejs.org/docs/)。

地图默认显示 6 条水系（长江、黄河、珠江、黑龙江、淮河、京杭大运河）和 25 处地形名称（14 处山脉、4 大高原、3 大平原、4 大盆地）。正文复用 `map-data.js`；真实河道来自 HydroRIVERS 与 OpenStreetMap，独立保存为 `river-centerlines.json`，高程生成器再输出 `china-rivers-data.js`。河谷使用更细的 DEM 并加密到约 1 千米网格，加入河道节点。河段在地形三角边处切分并检查中点贴合；省界重叠处使用可见上表面，数值接缝继续细分。边境与河口位于简化地形范围外时仍保留真实位置，使用同源 DEM 高程；资料缺口保留分段。蓝线表示中心线，不代表河宽或水位。来源、覆盖范围与复现方法见 [真实河道数据说明](RIVER-SOURCES.md)。高度倍率同步作用于河流与地形。名称拥挤时用短引线避让，空间不足时隐藏；分类目录保留全部名称，点选后优先显示并打开档案。

模型按需绘制，没有持续播放；支持鼠标、触摸和键盘。WebGL 不可用或上下文丢失时显示提示，省份选择、档案与平面地图入口保持可用。统一页面沿用右侧栏、左右切换与浏览器记忆。

供应文件已提交，运行与部署无需 npm。仅更新引擎时在可联网环境运行以下命令（临时安装固定版本的 Three.js 与 esbuild，退出时清理临时目录），再提交生成文件：

```sh
node content_sources/geo-map/scripts/build-three.mjs
make study-topics-data
```

### 河水流向与源头、去向

3D 页新增「跟着河水走」观察栏：选一条河，查看静态箭头，点「播放流向」连续观察或点「前进一步」单步查看。长江、黄河、珠江、黑龙江和淮河有顺流演示；京杭大运河受分段供水、闸泵调节，标南北端但不播放统一单向水流。地图目录与 `?river=` 深链接会同步选择演示河流，切换时暂停并从头开始。

每条水系标 2 个位置，共 12 个标记。绿点表示源区或上游，橙点表示入海区域、下游去向或南端。长江入东海，黄河入渤海；珠江有多个出海口，源区和入海区域用大致位置提示，资料未覆盖的部分不补画直线。黑龙江标两河汇合的干流起点和图内末端，说明出境后才到鄂霍次克海；淮河标源区和洪泽湖，说明还会分流入江、入海。不会把截断的河道末端标成海口。

端点、分段方向、解说与出处维护在 `china-3d-data.js` 的 `rivers[].flow`，方向与真实河道输入 SHA-256 绑定；更新河道时须重新核对分段顺序。`china-river-flow.js` 按贴地折线的水平弧长插值，保留原始分段，不靠经度单调或局部 DEM 海拔猜下游。箭头投影跟随视角和高度倍率，作为地图注记显示，速度仅用于教学。动画只更新箭头层，地形保持按需绘制。

默认不自动播放；可暂停后继续，隐藏河流、切换河流、切到后台、地图离屏、WebGL 中断及离开页面都会暂停，回来不自动续播。统一「动效与声音」偏好及系统减少动效生效时保留静态箭头和单步观察。无 WebGL 时仍可选择水系、阅读源区与去向。

### 长江与黄河沿河漫游

在「跟着河水走」选长江或黄河后，点「沿河漫游」启动镜头行程。两条路线各 12 站、共 24 站，从源区到入海口，镜头沿已有的真实贴地折线移动。长江沿线包含玉树、攀枝花、宜宾、重庆、宜昌、武汉、九江、南京、上海附近河段，以及虎跳峡、三峡等地形；黄河沿线包含兰州、银川、包头、三门峡、郑州、济南、东营附近河段，以及源区湖泊、龙羊峡、壶口与潼关附近。

每站停留约 8 秒，介绍所在地形并给出一个观察问题，可暂停、继续、重播、上一站／下一站、直接选站或切换「慢慢看／快一点」。进度按河道弧长计算，到入海口自动停止。进入时放大到河段视角，退出恢复进入前的视图；手动拖动、转向、缩放会暂停镜头。流向箭头播放和镜头漫游互相暂停，避免两个演示争抢视图。减少动效、页面隐藏、地图离屏、河流图层隐藏或 WebGL 中断也会暂停，不自动续播。没有 WebGL 时仍能选路线、逐站读介绍。

站点数据与出处集中在 `china-river-tour-data.js`，并绑定 `centerlinesSHA256`。锚点用来找附近真实河段，不把城市中心当作水上位置。每条路线保留原河道分段，黄河湖区缺口直接切到下一段，不生成补线。地形档案通过稳定 ID 关联。`china-river-tour.js` 管理河道定位、停站与行进计时，不修改地形数据。

深链接如 `china-3d.html?river=f20&tour=yangtze&stop=yibin`、`china-3d.html?river=f21&tour=yellow&stop=hukou` 可直接打开一站，刷新后保持该站且不自动播放；途中刷新回到最近到达的站点。原有省份、地形与河流深链接继续可用。

### 地形剖面仪

在 3D 地图工具栏点「拉线画剖面」，从陆地 A 拖到陆地 B，或依次点两处位置；Esc 或「取消拉线」退出，完成后恢复旋转。侧栏 SVG 显示沿线距离和原始采样海拔，并用 A、B 与地图对应。窄屏完成后展开侧栏；「清除剖面」移除结果和连线。

「西向东示范」沿北纬 32°从青藏高原到长江下游附近，用来观察总体西高东低与局部起伏。三级阶梯知识复用 `content.js` 的 `GM_STEPS`，不按单点海拔强行划分阶梯。示范端点及学习说明维护在 `china-3d-data.js` 的 `section`；采样、距离和 SVG 在 `china-terrain-section.js`，调用已有 `createSurfaceSampler`。

沿经纬度直线约每 4 千米采样一次（最多 1201 点），距离按各相邻采样点的球面距离累计。海拔与高度倍率无关，负海拔保留，缺数据处断开。横纵轴采用不同尺度，结果适合地理观察，不能用于精密测量。开始拉线会退出镜头漫游并暂停流向；Esc、触控取消、页面隐藏或 WebGL 中断会结束当前拉线并保留上次结果。回归：`node --test scripts/test_china_terrain_section.cjs`，另用浏览器验证拖动、两点选择、取消、倍率和宽竖屏。

## 3D 世界地图

从图谱首页、专题导航和世界地图进入 `world-3d.html`。地球仪复用 `world-geo.js` 的 177 个国家和地区及 `world-data.js` 的七大洲、四大洋和 10 处地标档案，不重复维护正文。支持鼠标或触摸旋转、滚轮或按钮缩放、方向键转动、Home 复位、点选国家、名称和地标定位；不自动旋转，按需绘制，离屏或后台不持续绘制。统一页面沿用右侧栏、左右切换与浏览器记忆。WebGL 不可用或上下文丢失时仍可从列表选择地点、读档案和进入平面图。

`world-3d-data.js` 维护默认视角、七洲定位点和三项观察任务，先由 `test/test-world-3d.js` 校验。地点链接使用原 ID，如 `?place=China`、`?place=o1`、`?place=wf2`，大洲使用 `?continent=africa`；选择后地址自动更新，刷新保留选择，不自动播放。经纬网以 30° 为间隔，金线为赤道，默认颜色只表示洲别，不模拟海拔；「昼夜与四季」另外提供简化光照演示。

平面底图的南极洲截到南纬 73°，地球仪单独使用 `world-3d-polar.js` 补上完整南极洲，来源同为 [world-atlas / Natural Earth](https://github.com/topojson/world-atlas)，固定版本 2.0.2，记录源文件 SHA-256。`scripts/build-world-3d.py` 只复用原底图生成器的解码函数，不改变平面图和原国家 ID。渲染通过本地 Three.js 的 CanvasTexture 将简化轮廓绘制到球面，经日期变更线的岛屿用连续经度处理。球面坐标、三角面朝向、纹理方向和日期变更线由 `scripts/test_world_3d.cjs` 校验。

```sh
python3 content_sources/geo-map/scripts/build-world-3d.py <countries-110m.json 路径>
node content_sources/test/test-world-3d.js
make study-topics-data
node --test scripts/test_world_3d.cjs
```

### 地球仪学习扩展

地图工具新增「地球五带」配色和六条重要线（赤道、南北回归线、南北极圈、本初子午线），各配说明与观察问题。五带采用约 23.5°、66.5° 的教学边界，色带覆盖陆地与海洋，不表示实时气温。点球面显示点击位置的近似经纬度和所属带；从目录定位显示的是参考点，不能用来代表整个国家的纬度范围。

新增「从中国去看海」「从赤道走向两极」「世界地标观察员」三条手动导览，共 15 站，支持前后站、重新定位、结束与 `?tour=latitude-trip&stop=antarctic` 深链接。每站读同一份地点档案；自主选择其他地点或工具视角会结束导览，手动拖动可继续观察本站。学习配色与重点线由 `layer=zones`、`line=equator` 保留。

18 道探索题提供地图观察、重试、提示和解析，支持全部再练和错题再练。答对记录使用稳定题目 ID 保存在本浏览器的 `study_world_globe_mastered_v1`；无法使用存储时保留本次状态。题目、五带、重点线与导览内容在 `world-3d-learning-data.js`，交互在 `world-3d-learning.js`，结构与原地点引用由 `test/test-world-3d.js` 校验；无 WebGL 时仍可阅读导览与答题。搜索支持原地点中文名和英文名，选中的国家在球面优先显示名称。

两点测距与 6 个经纬度寻宝任务由 `world-3d-tools-data.js`、`world-3d-tools.js` 维护；「昼夜与四季」由 `world-3d-sun-data.js`、`world-3d-sun.js` 维护，提供四个时节、4 组观察线索、一天播放与暂停、3 小时单步和四时昼长对照。减少动态、离屏、后台及 WebGL 中断时暂停，数值与坐标输入仍可使用。

「地理侦探」的 8 条线索集中在 `world-3d-detective-data.js`，判题与探索记录在 `world-3d-detective.js`。孩子可点球面国家或从列表作答，两步提示不扣分，查看答案不算找到，重新挑战保留已有记录。国家、地标和学习档案引用原 ID；中国任务接受原底图中的中国大陆与中国台湾省图形。记录使用 `study_world_globe_detective_v1`，只保存完成任务 ID。探索记录面板同时读取原探索题、寻宝记录，支持继续未完成或完成后重练；存储不可用时仍显示本页进度。五种玩法之间互斥切换，切换快捷视角或复位保留当前玩法，打开地点档案或导览时回到普通浏览。
