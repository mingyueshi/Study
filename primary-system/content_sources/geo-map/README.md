# 地理图谱

统一版入口为 `/geography/atlas/china.html`。本目录保存模板、数据和配套素材。改动后运行 `make study-topics-data`。

标题、导航和筛选使用统一侧栏，默认靠右，可切换到左侧并在本浏览器保存。竖屏按地图、档案的顺序阅读。横屏且内容区够宽时，档案放在地图旁边；窄屏上，侧边栏移到内容上方。

中国与世界动物地图的选取区位于地图下方，以带照片、名称和编号的卡片展示。点照片和点地图标记会同步选中同一只动物，按栖息地筛选时，照片卡与地图一起变化。

中国植物补充北京侧柏、安徽黄山松、河南牡丹、广东木棉、西藏青稞与宁夏枸杞；世界植物补充印度榕、日本柳杉、南非帝王花、欧洲山毛榉、安第斯巨型凤梨与西澳草树。新增资料核对见 [植物资料说明](PLANT-SOURCES.md)。

两张植物地图沿用地图下方的照片卡片，不使用下拉选择。地图编号、照片和档案联动，植物深链接使用 `?plant=植物ID`。窄屏或竖屏选择植物后会展开植物档案，便于阅读；宽屏档案默认在右侧，可切换到左侧并保存偏好。地图标记只表示代表分布或栽培地点，棉花、水稻、茶树等在正文中注明栽培情况。

中国和世界地图都可以换图层、看图例、点选地点或用下拉框定位。放大后可拖动地图，或在地图获得焦点后按方向键平移。「找一找」每轮随机出 5 题，点错时可读提示，答对再进下一题。

地图用于学习方位。中国省级轮廓由 DataV 边界数据简化而来，世界轮廓来自 Natural Earth 110m，山脉和多数二维河道为近似示意；长江、黄河的平面走向与 3D 页复用真实河道中心线，3D 页另用数字高程。中国图右下的小图显示南海诸岛和十段线。世界图使用等经距画法，靠近两极的陆地形状和面积会变形。

世界地图上方直接列出七大洲按钮，点击后逐洲突出轮廓并显示重点，点「全部大洲」返回全览。洲别选择也可用深链接，例如 `world.html?continent=africa#map`。切换图层或进入「找一找」时收起洲别高亮，回到七大洲自由探索后恢复。

图谱页面保留侧边导航，动物地图保留页头的地图切换入口。各页 hero 按主题配色，地图、档案、观察问题和目录用背景与边框区分。

## 数据与页面

地球仪的视觉参数、61 个代表城市和简化冰盖维护在 `world-3d-visual-data.js`，渲染与自转时钟在 `world-3d-visual.js`。本地高程图、来源、精度与重建方法见 [地球仪视觉素材说明](WORLD-VISUAL-SOURCES.md)。效果不会改变原地点 ID、球面测距、昼长结果与本机探索记录。

- `content.js`、`map-data.js` 和 `world-data.js` 分别维护图层元数据、中国档案和世界档案。省份 `facts` 每条记录有五个要点。世界国家与地区用地图几何中的英文名作 ID，其余地点继续用现有 ID，例如 `p110000`、`f20`、`n2`、`wf2`、`o1`。
- `world-data.js` 的 `GM_CONTINENTS` 同时维护洲别档案。每洲有 `location`、三条 `facts`（标题与正文）、`observe`、`places`（代表地点 ID）和 `source`。跨洲国家沿用本图既有的大洲映射。
- `atlas.js` 从已有档案生成地点索引，供目录、路线、图层定位、关联档案和练习共用。新增地点时保留原档案的 ID 规则，并在对应 SVG 中用 `data-id` 注册可点选的图形。原 ID 会出现在已有链接里。
- `atlas-data.js` 用地点 ID 组织路线和双向关联。每个路线站点填写一条观察提示。中国的邻居还会按中文名关联到世界地图中的对应记录。中外对照卡在 `map-data.js` 的 `GM_WORLD_TEASERS` 中维护，`places` 依次引用左右两个地点。
- `media-data.js` 用地点 ID 挂接素材，`media.js` 在地图档案、省域站和图册复用渲染。图册支持 `?place=地点ID`，例如 `gallery.html?place=f20`。素材保留来源页、作者和适用的授权链接。图片按原画面等比缩放，转成 JPEG 后保存在 `assets/`，影片只打开央视网。
- `shared.js` 提供投影、SVG 路径、世界底图和省域站卡片。中国与世界地图页各自绘制图层，由 `map-ui.js` 处理定位、图层切换、档案关联、缩放和练习。目录和路线页只加载档案数据。
- `animals-data.js`、`world-animals-data.js` 分别维护中国和世界的动物档案与栖息地图例，交互共用 `animals-app.js`。动物 ID 用于直达链接和 `assets/animals/` 下的同名 JPEG 照片。中国档案用 `adcode` 关联省域站，世界档案用 `mapPlace` 关联国家、地区或大洋。点位只标出代表栖息地。档案里的 `source` 是资料出处，照片来自另一页面时填写 `photoSource`。
- 动物与植物地图共用 `animals-learning.js`，提供关键词与观察状态组合筛选、随机认识未观察的动物或植物、上一种／下一种浏览和两种五题练习（看照片、读线索）。练习复用档案的 `clue` 与本地照片，按当前筛选抽题，答题后查看地点与线索，可重练本轮错题。观察需主动标记，可取消；中国动物、世界动物、中国植物、世界植物四张地图分开保存在当前浏览器，不随账户同步。存储受限时保留本次操作并显示提示。练习不自动计入观察，刷新后重新开一轮。植物搜索还覆盖学名和环境适应说明，提示使用对应的生长环境。回归测试为 `scripts/test_animals_learning.cjs`。
- `plants-data.js`、`world-plants-data.js` 维护植物档案，复用 `animals-app.js` 和 `animals.css` 的地图、筛选和照片交互。字段包括稳定 `id`、中文名 `name`、学名 `scientificName`、生境 `habitat`、代表地点 `place` 与经纬度 `point`，以及分布 `home`、适应方式 `adaptation`、观察线索 `clue`。中国用 `adcode`、世界用 `mapPlace` 关联原地图；`source` 链接植物智或邱园等资料，`photoSource` 链接照片来源页。本地 JPEG 保存在 `assets/plants/`，无需运行时联网。新增或改动字段时同步更新 `test/test-geo-map.js` 的结构与引用校验。
- 地图链接用 `?place=地点ID#map`，例如 `china.html?place=f20#map`，自动选中对应地点和图层。需要保留路线时加上 `&route=路线ID`。同一地点也可以在另一可见图层打开，例如 `world.html?place=China&layer=home#map`。

动物照片按原比例缩放并压缩为 JPEG。大熊猫照片由 J. Patrick Fischer 拍摄，采用 [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) 许可。褐马鸡照片由 Somongkol Teng 拍摄，采用 [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/) 许可。原图及其他照片的出处见页面档案。

`china-geo.js` 和 `world-geo.js` 由脚本生成。重新生成时可传入本地源文件，省略参数时脚本会尝试联网下载。打开学习页面只读取本目录的文件。

```sh
python3 content_sources/geo-map/scripts/build-geo.py <100000_full.json 路径>
python3 content_sources/geo-map/scripts/build-world.py <countries-110m.json 路径>
node content_sources/test/test-geo-map.js
```

## 3D 中国地图

`china-3d.html` 由地图首页、中国地图和专题导航进入；省域站也可带原省份 ID 返回立体地图。地址支持 `?place=p710000`，兼容 `?adcode=710000`。点选会更新地址，刷新仍显示该省份；无效参数提示重新选择。地形定位也支持深链接，例如 `?landform=f9` 直达青藏高原；`?river=f20` 定位长江并查看原档案。旋转、缩放、标签显隐和高度倍率只调整视图，不写学习记录；教学挑战另在当前浏览器保存独立完成记录。

省名默认显示，使用浅底大字标签，可直接点省名打开档案；密集处用引线避让，空间不足时可放大或从省份列表选择。省界使用固定像素宽度的深线与浅色衬边，选中省份显示橙色粗边。「省份分色」用不同颜色区分相邻省份，仍保留地形起伏，颜色不代表海拔。

`china-3d-data.js` 维护观察任务、海拔色阶、省份配色、高度倍率、地形标签和分类定位目录，结构由 `test/test-geo-map.js` 校验。正文复用 `map-data.js`，省界与南海小图复用 `china-geo.js`，不复制省份档案或修改原地点 ID。`china-terrain-data.js` 是由公开 DEM 生成的本地真实高程网格，包含 447599 个顶点和 843942 个三角形。选中省份会高亮颜色与边界；「省份抬起」可切换示意抬起，只改变模型显示位置。配色、显示倍率和抬起都不改变原海拔。高程来源、精度与重建步骤见 [真实地形数据说明](TERRAIN-SOURCES.md)。3D 渲染采用本地 Three.js 0.180.0 与 OrbitControls（MIT），来源为官方 npm 包，许可见 `assets/vendor/THREE-LICENSE.txt`，技术资料见 [Three.js 官方文档](https://threejs.org/docs/)。

地图默认显示 6 条水系（长江、黄河、珠江、黑龙江、淮河、京杭大运河）和 25 处地形名称（14 处山脉、4 大高原、3 大平原、4 大盆地）。正文复用 `map-data.js`；真实河道来自 HydroRIVERS 与 OpenStreetMap，独立保存为 `river-centerlines.json`，高程生成器再输出 `china-rivers-data.js`。河谷使用更细的 DEM 并加密到约 1 千米网格，加入河道节点。河段在地形三角边处切分并检查中点贴合；省界重叠处使用可见上表面，数值接缝继续细分。边境与河口位于简化地形范围外时仍保留真实位置，使用同源 DEM 高程；资料缺口保留分段。蓝线表示中心线，不代表河宽或水位。来源、覆盖范围与复现方法见 [真实河道数据说明](RIVER-SOURCES.md)。高度倍率同步作用于河流与地形。名称拥挤时用短引线避让，空间不足时隐藏；分类目录保留全部名称，点选后优先显示并打开档案。

模型按需绘制，没有持续播放；支持鼠标、触摸和键盘。WebGL 不可用或上下文丢失时显示提示，省份选择、档案与平面地图入口保持可用。统一页面沿用右侧栏、左右切换与浏览器记忆。

供应文件已提交，运行与部署无需 npm。仅更新引擎时在可联网环境运行以下命令（临时安装固定版本的 Three.js 与 esbuild，退出时清理临时目录），再提交生成文件：

```sh
node content_sources/geo-map/scripts/build-three.mjs
make study-topics-data
```

### 按区域读取地形与颜色查表

首屏读取 `china-terrain-index.js`，包含 65470 个概览三角面、预计算河线、详细块目录与指纹，不加载约 10.8 MB 的全国详细 DEM 脚本。详细地形按东经 73°、北纬 17°为原点，划成 4°×4°的 96 个本地块；放大后按视口选择最多 12 块，同时读取最多 3 块，通常最多缓存 24 块。离开视口的读取可以取消，旧数据不会覆盖新任务。缩回全图后使用概览，详细数据通过缓存再利用与淘汰控制内存。

详细块逐面保留原网格的 843942 个三角形和整米高程，概览与详细块均保留 51482 段省界。地形仍按省份合并绘制，保留独立高亮与示意抬起。当前 Three.js 已使用 WebGL2；各省几何不同，不用同一份几何的 InstancedMesh 冒充地形优化。省界与河线继续使用现有实例化线段接口，不承诺固定帧率翻倍。

海拔点选、阶梯坐标作答与剖面会先保留并读取沿线需要的详细块，再从原始采样器读取。临时保留期间缓存可超过通常上限，完成后释放并恢复淘汰；正在读取时切换任务会使旧反馈失效。读取失败不以概览海拔计分，概览、目录与原进度仍可使用；点「再试一次」重试视口细节，坐标作答可重新提交。静态文件直接打开也可通过本地脚本块使用，无运行时外部数据请求。

`china-3d-geometry.js` 把 −500—9000 米的整米色阶预生成 Float32 查找表，批量填充顶点颜色，避免逐顶点分配 Color 对象；颜色与原线性插值相同。`scripts/build-terrain-stream.py` 从既有 DEM 与水文掩膜生成概览、详细块和两级图层标志；`scripts/bake-terrain-water.cjs` 用原采样器预计算干流、支流贴地线段，使浏览器不再逐段切分全国河道。元数据绑定 DEM、河道、湖泊和几何代码输入指纹。重建说明见 [地形来源](TERRAIN-SOURCES.md)。

回归：`node content_sources/test/test-china-terrain-stream.js` 验证每个详细三角形、高程、省界与源网格一一对应；`node --test scripts/test_china_terrain_stream.cjs` 验证颜色、空间索引更新、视口选择、并发、去重、取消、缓存、失败重试与迟到回调。

### 流域、支流与立体湖面

新增长江、黄河、珠江、黑龙江与淮河上中游的 5 处汇水图层，16 条代表支流或水系支干采用浅蓝色，与深蓝干流和湖蓝水面区分。京杭大运河保留跨流域人工水路说明。6 处湖泊改用平整的半透明水面和示意湖盆，关闭后恢复原地形；原始高程和读数不变。长江三角洲、黄河三角洲与珠江口可一键放大，并返回整条河流。面积统计、跨国范围、淮河部分覆盖、湖面估计方法、来源与复现见 [水文图层说明](HYDROLOGY-SOURCES.md)。

### 地图小研究员、海拔柱与倍率对照

「地图小研究员」增加三级阶梯定位、四条支流水系拼图和 5 道省界与山河关系观察题。三级阶梯按大致地理区域判断，不用单点海拔阈值代替区域；示意分界附近约 35 千米内不强判对错。青藏高原、柴达木盆地与四川盆地、天山、东部高山等例子用于校验口径。阶梯挑战可点地形或输入经纬度；拼图沿用真实河道的概化轮廓，可拖动，也可先选支流再选位置字母。湘江明确标作经洞庭湖水系与长江相连，独立拼好四条后主图中的长江高亮。

观察题定位晋陕峡谷、黄河几字弯、四川高低变化、太行山与三峡，先观察，再用两步提示或揭示解析。题目附出处，不把行政边界、河流与山脉简单画等号。查看参考位置或解析后须重新挑战，才计入独立完成。历史完成保存在 `study_china_3d_learning_v1`，与原侦探、寻宝记录分开；`?learn=steps`、`?learn=puzzle`、`?learn=questions` 可直接进入相应模式。无 WebGL 时仍可输入坐标、拼图和阅读作答。

点地形后可钉住刚才的海拔，最多 6 根半透明读数柱，支持逐根拔掉或全部清除；只保留在当前页面。数字始终来自原始高程采样，不随显示倍率、湖盆与省份抬起改变。柱子是读数标记，最低显示长度也只是为了看清。「1×／50× 左右对照」用同一场景和相机分两次绘制，共享旋转、缩放和配色；每半幅分别以对应倍率拾取地形。对照时隐藏读数柱和单图名称层，退出恢复原视角；单图可一键切到 1× 或 50×。

镜头跳转到湖泊、支流或教学观察点时清除上一个点的海拔读数，需重新点地形读取。完成拼图或展示参考后禁用「看参考位置」，避免重复操作给出相互矛盾的完成提示。

文案、题目、出处与概略阶梯边界维护在 `china-learning-data.js`，判题、进度与拼图交互在 `china-learning.js`，海拔柱和双视口坐标换算在 `china-learning-visual.js`。新增结构先运行 `node content_sources/test/test-china-learning.js`；纯逻辑回归为 `node --test scripts/test_china_learning.cjs`。修改后运行 `make study-topics-data`，并在实际浏览器核对拖拽、双视口点选与旧玩法互斥。

### 河水流向与源头、去向

3D 页新增「跟着河水走」观察栏：选一条河，查看静态箭头，点「播放流向」连续观察或点「前进一步」单步查看。长江、黄河、珠江、黑龙江和淮河有顺流演示；京杭大运河受分段供水、闸泵调节，标南北端但不播放统一单向水流。地图目录与 `?river=` 深链接会同步选择演示河流，切换时暂停并从头开始。

每条水系标 2 个位置，共 12 个标记。绿点表示源区或上游，橙点表示入海区域、下游去向或南端。长江入东海，黄河入渤海；珠江有多个出海口，源区和入海区域用大致位置提示，资料未覆盖的部分不补画直线。黑龙江标两河汇合的干流起点和图内末端，说明出境后才到鄂霍次克海；淮河标源区和洪泽湖，说明还会分流入江、入海。不会把截断的河道末端标成海口。

端点、分段方向、解说与出处维护在 `china-3d-data.js` 的 `rivers[].flow`，方向与真实河道输入 SHA-256 绑定；更新河道时须重新核对分段顺序。`china-river-flow.js` 按贴地折线的水平弧长插值，保留原始分段，不靠经度单调或局部 DEM 海拔猜下游。箭头投影跟随视角和高度倍率，作为地图注记显示，速度仅用于教学。动画只更新箭头层，地形保持按需绘制。

默认不自动播放；可暂停后继续，隐藏河流、切换河流、切到后台、地图离屏、WebGL 中断及离开页面都会暂停，回来不自动续播。统一「动效与声音」偏好及系统减少动效生效时保留静态箭头和单步观察。无 WebGL 时仍可选择水系、阅读源区与去向。

### 长江与黄河沿河漫游

在「跟着河水走」选长江或黄河后，点「沿河漫游」启动镜头行程。两条路线各 12 站、共 24 站，从源区到入海口，镜头沿已有的真实贴地折线移动。长江沿线包含玉树、攀枝花、宜宾、重庆、宜昌、武汉、九江、南京、上海附近河段，以及虎跳峡、三峡等地形；黄河沿线包含兰州、银川、包头、三门峡、郑州、济南、东营附近河段，以及源区湖泊、龙羊峡、壶口与潼关附近。

每站停留约 8 秒，介绍所在地形并给出一个观察问题，可暂停、继续、重播、上一站／下一站、直接选站或切换「慢慢看／快一点」。进度按河道弧长计算，到入海口自动停止。进入时放大到河段视角，退出恢复进入前的视图；手动拖动、转向、缩放会暂停镜头。流向箭头播放和镜头漫游互相暂停，避免两个演示争抢视图。减少动效、页面隐藏、地图离屏、河流图层隐藏或 WebGL 中断也会暂停，不自动续播。没有 WebGL 时仍能选路线、逐站读介绍。

站点数据与出处集中在 `china-river-tour-data.js`，并绑定 `centerlinesSHA256`。锚点用来找附近真实河段，不把城市中心当作水上位置。每条路线保留原河道分段，黄河湖区缺口直接切到下一段，不生成补线。地形档案通过稳定 ID 关联。`china-river-tour.js` 管理河道定位、停站与行进计时，不修改地形数据。

深链接如 `china-3d.html?river=f20&tour=yangtze&stop=yibin`、`china-3d.html?river=f21&tour=yellow&stop=hukou` 可直接打开一站，刷新后保持该站且不自动播放；途中刷新回到最近到达的站点。原有省份、地形与河流深链接继续可用。

### 地形剖面仪

在 3D 地图工具栏点「拉线画剖面」，从陆地 A 拖到陆地 B，或依次点两处位置；Esc 或「取消拉线」退出，完成后恢复旋转。侧栏 SVG 显示沿线距离和原始采样海拔，并用 A、B 与地图对应。窄屏完成后展开侧栏；「清除剖面」移除结果和连线。

「西向东示范」沿北纬 32°从青藏高原到长江下游附近，用来观察总体西高东低与局部起伏。三级阶梯知识复用 `content.js` 的 `GM_STEPS`，不按单点海拔强行划分阶梯。示范端点及学习说明维护在 `china-3d-data.js` 的 `section`；采样、距离和 SVG 在 `china-terrain-section.js`，调用已有 `createSurfaceSampler`。

沿经纬度直线约每 4 千米采样一次（最多 1201 点），距离按各相邻采样点的球面距离累计。海拔与高度倍率无关，负海拔保留，缺数据处断开。横纵轴采用不同尺度，结果适合地理观察，不能用于精密测量。开始拉线会退出镜头漫游并暂停流向；Esc、触控取消、页面隐藏或 WebGL 中断会结束当前拉线并保留上次结果。回归：`node --test scripts/test_china_terrain_section.cjs`，另用浏览器验证拖动、两点选择、取消、倍率和宽竖屏。

## 中国地形互动玩法

`china-adventures-data.js` 集中维护 8 条猜省区线索、4 个坐标寻宝任务、5 站山地飞行和 8 站大运河虚拟行船。先运行 `node content_sources/test/test-china-adventures.js` 校验结构与稳定引用。地图、省名和答案按钮统一交给 `china-adventures.js` 判定；寻宝按球面距离与任务允许误差判定，也可输入坐标。记录仅保存稳定任务 ID，键为 `study_china_3d_missions_v1`，与世界版分开；提示不扣分，展示答案不计入完成，重新挑战保留已有完成记录。无 WebGL 时仍可用省名按钮与坐标输入。

山地飞行串联昆仑山、祁连山、黄土高原、太行山与华北平原，是包含低地跨越的虚拟观察路线；运河行船沿原 `f43` 河道，保留原有分段，不表示实际全线通航或水流方向。两条路线共用 `GMRiverTour.createTour` 的暂停、逐站、速度与后台停止规则，支持 `?tour=ridge-flight&stop=qilian`、`?tour=canal-boat&stop=hangzhou`。与剖面和侦探玩法互斥，入口使用直接选择按钮。

湖面取自 [Natural Earth 1∶1000 万湖泊数据](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-lakes/)，原输入为 `nvkelso/natural-earth-vector` 仓库的 `geojson/ne_10m_lakes.geojson`，完整输入 SHA-256 保存在 `lakeSource`。选取青海湖、鄱阳湖、洞庭湖、太湖、洪泽湖和巢湖六处轮廓，用约 0.025°网格在湖内读取 DEM 来估计统一水面高度；水面按湖泊与省界轮廓裁切剖分，湖盆只修改显示面片。没有有效高程时不生成水面；不表示实时岸线、水位或水深。雪线观察默认以 5000 米为界，现可拖动滑块在 0—9000 米间调节；白色是统一海拔观察示意，不能据此判断真实雪线或永久积雪。

统一模板由生成器接入现有 `static/speech.js`。配音由用户主动开始，可读剖面或当前站点，也可开启到站讲解；讲解时等待，读完后继续停站计时，避免解说被行程截断；默认不发声。停止、换玩法、后台、离屏和上下文中断使旧回调失效；没有语音服务时按钮禁用，文字继续可读。自动化使用语音桩检查状态，设备实际发声需用本机中文语音试听。

回归：`node --test scripts/test_china_adventures.cjs`，以及原地形、剖面与漫游回归。修改后运行 `make study-topics-data` 同步模板和本地静态资源。

### 环球旅行、计时与主题图层

### 中国地形视觉观察

右侧独立滚动栏新增「地形观察工具」，可边看地图边调节。每 500 米一档的等高线直接沿当前三角网线性插值，默认关闭，打开后按省份分帧生成；按需 DEM 切换时只重建涉及省份，已解码块的线段用弱引用缓存。线随倍率、左右对照和省份抬起同步，不触发全国详细 DEM 下载。

光照有东、南、西、北及恢复西南方向预设，也可拖动 0—359°方位滑块，指南圈显示光从哪边来；它改变坡面明暗，不改地形。14 个山脉标签加 ⛰ 微图标，名称与稳定 ID 沿用原档案。

动态变白高度范围为 0—9000 米、每 100 米一档，默认 5000 米，拖动自动开启，原「雪线观察」按钮可关闭。着色器按原始海拔插值作阈值判断，不逐次重写顶点颜色或高度，三种地图配色都可使用；详细块更新时同步原海拔属性。地形不透明度从 100％到 0％，只控制上表面与模型侧面；省界、河线、湖面和等高线继续可观察。全部显示效果保留原始海拔、剖面和判题。

参数与文案在 `china-terrain-visual-data.js`，显示代码在 `china-terrain-visual.js`，来源与边界见 [地形视觉说明](TERRAIN-VISUAL-SOURCES.md)。新源契约 `node content_sources/test/test-china-terrain-visual.js`，几何回归 `node --test scripts/test_china_terrain_visual.cjs`；原 `china-terrain-play.js` 保留旧页面与测试需要的静态雪线回退。
## 平面图谱交互标注与回放

`map-discovery-data.js` 维护 34 个省级行政区的中心参考点和原文索引，点位取自 DataV.GeoAtlas 的 `100000_full.json`，按既有省份 ID 匹配，原输入 SHA-256 留在出处元数据。省会、首府名称继续读 `map-data.js`；直辖市和特别行政区按自身名称标注。点选后在地图上显示参考点、醒目省域与地形气候短提示，气候正文引用原省份档案，不再复制一份。找一找模式隐藏这些提示。

中国平面地图新增长江、黄河的源区到入海口回放。轮廓直接复用 `china-rivers-data.js` 的已有分段，城市与源区、海口引用 `china-river-tour-data.js`。`map-discovery.js` 按投影后的弧长控制水滴与高亮线，进度仅表示图面行程，不冒充实际水速、城市间距离或完整真实行程。可播放、暂停、从头重看、拖进度和直接选站，抵达海口后停止。资料缺口保持分段；切层、找一找、离屏、后台与减少动态时暂停，减少动态仍能手动拖动。

3D 地形剖面增加滑块、曲线拖动、最高点与最低点按钮；曲线上探针与地图黄点同步。`GMTerrainSection.inspect/indexAt` 只选原始采样点，显示离 A 的距离、原始海拔及与 A 的高低差；空白不补零，负海拔保留，高度放大不改变读数。完成新剖面时从 A 开始，取消重画时保留上次探针；已有剖面在 WebGL 中断后仍可用滑块阅读。

世界地图增加从中国出发的 14 个陆上邻国与 6 个隔海相望国家探索。通过原邻居档案与国家档案的稳定关联着色、选国与阅读一句特色，正文继续使用 `GM_NEIGHBORS.note`。支持直接点地图、国名按钮和前后浏览；陆上和隔海分开说明。`world.html?neighbors=land&layer=home&place=India` 可直接进入邻居视图。切到其他图层或找一找时退出提示，不影响七洲选择与原档案深链接。

共享 `GMMapUI.mount` 增加 `onSelect` 回调与公开的 `choose`，沿用原图层、缩放、档案与游戏规则；地图外的按钮也走同一套选择流程。新增数据校验为 `node content_sources/test/test-map-discovery.js`，行为回归为 `node --test scripts/test_map_discovery.cjs`。发布继续用 `make study-topics-data`，两张平面地图的资源也附带内容指纹。

## 中国省份文化

`province-culture-data.js` 是文化正文的主来源，按稳定 `adcode` 关联原 `GM_PROVINCES`，不重复维护行政区名称、类型、省会与地图。每省列出 `shortNames`（既有简称与常用别称）、两项 `specialties`、一项 `customs`、两项 `landscapes`、`question` 与 `explanation`。每条内容都有 `name`、具体 `location`、`detail` 与指向来源索引的 `sources`。共 170 项文化条目和 62 项来源索引；特产也包括食品与工艺品，不把全部特产都称为地理标志产品。民俗和传统技艺标明流传地区，跨省项目保留共同传承说明，观察问题用于继续查证。

`province-culture.js` 渲染与筛选，`province-culture.css` 控制界限、字号与宽屏布局。底图、南海小图复用 `china-geo.js` 与 `shared.js`，行政区中心参考点复用 `map-discovery-data.js`。省会／首府读原字段，直辖市和特别行政区不设省会，显示本身名称作为识记参考。`?adcode=` 指定档案，`q` 与 `type` 可组合筛选；无效省码提示后展示北京。换省份使用浏览器历史，过滤只更新当前历史项，刷新和前后退保留当前状态。无本机学习存档或数据库写入。原省域站仍为自然地理正文主出处。

新增字段先由 `node content_sources/test/test-province-culture.js` 校验 34 省码、简称兼容、五类资料、地图位置和来源引用，再运行 `node content_sources/test/test-geo-map.js`、`make study-topics-data`、`make test-frontend` 与 `.venv/bin/python manage.py test catalog.test_study_topics`。外部资料由读者主动打开，阅读正文和地图无需联网。
