# 植物地图扩充资料说明

中国与世界植物地图各由 24 种扩充为 30 种，新增条目接在原有条目之后，保留旧 ID、编号、深链接和本地观察记录。中国代表点覆盖 26 个省级行政区，世界地图继续覆盖七大洲。

地图上的点表示一个代表分布或栽培地点，不是完整分布范围。照片用于认识植物外形，不表示全部拍摄于地图标点处。例如，青稞点位选在西藏日喀则江孜，配图是青海贵南的青稞田。牡丹、青稞与枸杞在正文中说明栽培背景。

所有照片保存于本目录的 `assets/plants/`，随专题生成到本地静态目录，浏览和练习不依赖外网。下列链接供核对资料与原始照片；每份档案的 `source`、`photoSource` 同时保留主出处。

- 印度榕的代表地点位于加尔各答附近的豪拉植物园：[印度植物调查局资料](https://bsi.gov.in/uploads/userfiles/file/ENVIS/Brochure/FICUS%20IN%20WEST%20BENGAL-F.pdf)。
- 欧洲山毛榉的落叶特点：[牛津大学植物标本馆](https://herbaria.plants.ox.ac.uk/bol/plants400/Profiles/EF/Fagus)；叶片形态：[昆特兰理工大学植物资料](https://plantdatabase.kpu.ca/Plant/fasy)。
- 西澳草树的地区与生长特征：[南澳植物园植物查询](https://plantselector.botanicgardens.sa.gov.au/Plants/Details/361)。

生境使用便于儿童比较的概括分类。世界地图的「热带森林」包括印度榕所在的季节性干湿变化地区；「冬雨林地与灌丛」也涵盖南非开普地区与澳大利亚西南部，不只指地中海沿岸。
