# 历史时间轴系统

统一版入口为 `/history/timeline/timeline.html`。本目录保存模板、数据和配套素材。改动后运行 `make study-topics-data`。

## 从哪一页开始

| 页面 | 可以做什么 |
| --- | --- |
| `index.html` | 按时间选时代站，或进入总时间轴查找大事。 |
| `timeline.html` | 浏览 9 个时代里的 126 件大事，按事件、朝代或年代搜索，选择查看视角，也可以筛出带素材的大事。 |
| `era.html?era=voyage` | 顺着年代读一个时代的完整事件卡片，看这个时代的教学图集、中外对照和相关朝代，向前或向后换一站。 |
| `event.html?event=tc27` | 单独打开一件大事。带素材的详情可以看大图、读图注和观察提示，部分素材可听录音。也能查看同一时期另一边发生了什么，沿本时代继续读，或回到总轴上的原位置。 |
| `dynasties.html` | 读夏到清 16 个朝代怎样建立和结束，回到各自的时代站看中外大事。公元纪年小课堂有数轴、算法和练习。 |

总轴用左侧常驻工具栏放搜索、视角和时代导航，右侧从大事开始读。正文够宽时，中国史在左，世界史在右。竖屏空间较紧时，两轨按同一年代顺序排成单列，卡片标出各自所属的轨道。更窄时，工具栏收成可展开的区块。上下间距用来表示先后，长时段采用代表年代排序。同一行使用相同的排序年代。

30 组同期对照通过事件编号关联。点事件卡上的「同期对照」可跳到另一轨。如果目标被筛选藏起来，时间轴会恢复双轨全览。点一组精选对照可打开事件页并直接定位到对照说明。

9 个时代都收录了外部素材，共 33 张图片和 1 段登月录音。图像包括文物、遗址、古籍、地图、艺术作品和历史照片。图注说明素材是原物照片、摹本还是复原图，附有出处。图片和录音保存在本目录，标有「需联网」的出处和延伸资料可按需打开。

## 数据与链接

| 文件 | 负责什么 |
| --- | --- |
| `content.js` | 时代站的 id、顺序、名称、年代范围、主题色和中外导读。 |
| `timeline-data.js` | 中国史和世界史事件、同期对照与精选对照。 |
| `media-data.js` / `assets/history/` | 按事件 id 归档的教学素材和本地媒体文件。图片为缩放或压缩后的教学副本，出处可查看原件与授权。 |
| `dynasty-data.js` | 朝代速览与详情共用的朝代带、朝代更替、公元纪年小课堂。 |
| `shared.js` | 共用时代与事件索引、年代行、事件卡、同期对照入口和动态锚点。 |
| `*-app.js` | 各页面的渲染和交互。 |

- 事件用 `tc数字`（中国轨）或 `tw数字`（世界轨）作为稳定 id，`era` 指向所在时代，`year` 用于显示，`sort` 用于排序。公元前年份记负数，长时段取代表年代。正文、标签、标题和图标由各页直接复用。
- 事件链接采用 `event.html?event=事件id`，总轴定位用 `timeline.html#card-事件id` 或 `timeline.html#era-时代id`，时代站也支持 `#card-事件id`。已有 id 供书签和页面互链使用。
- 素材条目包含标题、图注、观察或听读提示、署名、授权和原始出处。图片还要填写实际宽高和替代文字。音频用 MP3，媒体文件放在 `assets/history/`，出处和延伸资料使用 HTTPS 链接。
- 每组对照的 `china` 和 `world` 分别指向两条轨道、同属一个时代。对照允许一定年代差，测试将差值限定在 350 年以内。
- 朝代带的 `era` 指向与其建立阶段相关的时代站。速览和更替页共用同一个 `id`、`name`、`span`、`startYear` 与 `endYear` 等字段。深链接采用 `dynasties.html#dyn-朝代id`，更替桥的 `from` 与 `to` 连接相邻的两个朝代带。
- 年代用通行约数，传说明确标注，数据字符串使用中文标点。增改数据后运行下方校验。

```sh
node content_sources/test/test-timeline.js
```
