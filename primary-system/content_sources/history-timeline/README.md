# 历史时间轴系统

统一版入口为 `/history/timeline/timeline.html`。本目录保存模板、数据和配套素材。改动后运行 `make study-topics-data`。

## 从哪一页开始

| 页面 | 可以做什么 |
| --- | --- |
| `silk-road.html` | 切换陆海路网、地图点选城市、聚焦或全览，探索贸易品、文化交流和已有精讲。 |
| `silk-city.html?city=quanzhou` | 城市的地理、贸易作用、材料证据、讨论问题与时间轴入口。 |
| `ancient-science.html` | 按六个领域与关键词浏览 12 个科技档案，直达三个原理演示。 |
| `technology.html?topic=pi` | 阅读原理、分步解释、实物材料、影响、辨误与讨论题，联系人物和中外时间轴。 |
| `index.html` | 按时间选时代站，或进入总时间轴查找大事。 |
| `timeline.html` | 浏览 9 个时代的 213 件大事、38 组中外对比和 9 条因果线。可按关键词或文明专题筛选，点击朝代看疆域，展开事件卡内的人物名片。 |
| `era.html?era=voyage` | 从侧栏切换时代或定位本时代大事，在主区读时代导读、双轨事件卡片、图集、中外对照和相关朝代。 |
| `event.html?event=tc27` | 在主区读大事正文、看大图和图注、听录音或对照同期事件。可以沿阅读链继续读，也可以从侧栏打开同一时代的其他事件，或返回总轴上的原位置。 |
| `territory.html` | 独立的历史疆域地图；在同一底图上比较 16 个朝代、22 个阶段，自动播放、暂停、叠图、缩放与拖动。 |
| `dynasties.html` | 读十六个朝代的更替故事，学习公元纪年、数轴与练习；各朝代卡可进入对应疆域阶段。旧地图书签仍可用。 |
| `people.html` | 历史人物馆：按身份、时代和名字或作品筛选 24 位人物，切换名片与人物关系网，沿 18 条有出处的关系继续阅读。 |
| `person.html?person=li-bai` | 人物档案：名片、图注、主要事迹、关键决策与创作选择、人物关系、相关事件和时代入口。 |
| `civilizations.html` | 世界文明巡礼：八座文明站，可搜文明、地区与知识线索，按建筑、文字、制度、成就浏览，或选择两座文明围绕同一问题比较。 |
| `civilization.html?civilization=maya` | 文明档案：范围与年代、四个主题知识站、图像观察、讲解参考、材料局限、出处及时间轴入口。 |

总轴沿用统一系统默认右侧的工具栏，可移到左侧并保存选择；竖屏和窄屏可展开工具。正文够宽时，中国史在左，世界史在右。竖屏空间较紧时，两轨按同一年代顺序排成单列，卡片标出各自所属的轨道。上下间距用来表示先后，长时段采用代表年代排序。同一行使用相同的排序年代。

38 组同期对照通过事件编号关联。「同期对比」视图并列显示中国史和世界史的日期、故事，关键词命中任一侧时保留整组。世界文明专题筛选使用组内世界事件的标签。点事件卡的「同期对照」可跳到另一轨，筛选隐藏目标时会放宽条件。精选对照可打开事件页并直接定位到对照说明。

213 件大事中，中国 72 件，世界 141 件。新增事件在详情页附机构出处。世界文明专题覆盖美洲、非洲、阿拉伯及相关地区，可用 `timeline.html?view=world&region=americas` 直达。跨区域传承按所讲的问题归入专题，例如造纸传播连接中亚、西亚和伊比利亚。

- 「追踪因果线」可选 9 条线索并跳到任一事件卡。实线表示传播或推动后续行动，虚线表示提供条件。逐段文字说明证据、作用与边界，「查看出处」可访问机构资料。`timeline.html?chain=paper#timeline-causes` 打开造纸术到文艺复兴书籍的线索。
- 点击朝代色带可预览疆域图，多阶段朝代可切换示意年份。可从弹窗进入同一阶段的地图专题，或筛选这个朝代的中外大事。预览沿用疆域专题的自然底图和历史轮廓。
- 关键事件可展开人物名片，查看图像及图注、生卒年代和简介，再进入人物馆档案。同期对照和事件详情复用相同的人物与事件关联。

## 年代定位与阅读链

- 年代窗口为「全历史」「前后 500 年」「前后 100 年」。缩放围绕当前阅读年代显示局部事件，不把卡片间距变成按比例的时间尺。
- 输入「公元前 221 年」「前 221」「−221」「唐朝」等可定位。没有恰好那年的事件时显示最近已收录记录，长时段按代表年代定位。零年、超出收录范围和无效文字会提示，不改变当前结果；年代滑块直接从公元前 1 年跨到公元 1 年。
- 点顶部朝代色带，查看该朝代年代范围内的中外事件；滚动时按当前阅读年代高亮，交接和并立年份可高亮多个色块。朝代色块按顺序排列，宽度不代表时长。
- `timeline.html?year=-221&zoom=100`、`timeline.html?dynasty=tang`、`timeline.html?view=pair` 可分享年代窗口或对比视图。原有 `#card-`、`#era-` 和 `#timeline-tools` 书签继续可用，`#pair-p6` 可直达指定对比。筛选隐藏已定位的卡片时会解除该定位，刷新可接着看当前视角和年代窗口。
- 每件事件详情底部增加阅读链。`reading-data.js` 维护 43 条带理由的首选关联，例如「商鞅变法」→「秦统一中国」；其余事件沿同轨年代继续，末尾如有更晚的另一轨事件则引导过去。所有阅读链只向后推进，最后一件返回时间轴选新线索。

9 个时代都收录了外部素材，共 33 张图片和 1 段登月录音。图像包括文物、遗址、古籍、地图、艺术作品和历史照片。图注说明素材是原物照片、摹本还是复原图，附有出处。图片和录音保存在本目录，标有「需联网」的出处和延伸资料可按需打开。

## 历史疆域地图

独立的 `territory.html` 把夏到清 16 个朝代编成 22 个观察阶段。朝代更替与公元纪年保留在 `dynasties.html`，两页双向连接。在同一个东亚自然底图上，以半透明填色与轮廓线圈出各阶段范围。三国、南北朝和宋辽金等并立政权分别用色，星标显示都城或中心地点。夏用虚线表示黄河中游的主要活动地区。

- 在侧栏选择朝代和该朝代的具体阶段，或在地图旁前后翻阶段、拖动时间条、缩放和平移。
- 点「自动播放」按时间顺序查看，每阶段停留 6 秒或 10 秒，显示下一阶段提示，到最后一阶段自动停止。「暂停播放」保留本阶段的剩余停留时间，可继续或从头播放。播放全程保持当前地图视角；手动换阶段、点选区域、缩放、拖动、叠图、展开观察题或参考图时暂停，离屏或进入后台也会暂停。减少动态效果时保留手动查看。
- 默认标出相比时间轴上一阶段的变化：绿色是新增覆盖范围，橙色斜线是减少覆盖范围，重叠部分保留淡化的政权颜色。两阶段分别合看所有已画政权，再按轮廓扣除共同部分，政权内部换色不算范围增减。每个阶段有一句变化说明；起点不显示增减，暂停仍保留变化层，也可关闭。变化层固定比较上一阶段，与自行选择的紫色对照轮廓相互独立。
- 叠加另一阶段时，紫色虚线表示对照范围，两层共用投影与视窗。切换阶段保留手动指定的对照，两阶段相同时暂用上一阶段，首张用下一阶段。「看全图」恢复统一视角，「聚焦本阶段」定位当前圈线。
- 点地图色块或颜色图例可突出对应区域，地图上的色块也可用键盘选择。底图包括海岸线、黄河、长江等河流。
- 新深链接为 `territory.html?map=qing#territory-maps`，兼容 `map=han` 等已有朝代 id。旧 `dynasties.html?map=qing#territory-maps`、只带地图参数或 `#territory-maps` 的书签转到新页并保留参数；带 `#dyn-`、`#cal-title` 等正文锚点时继续留在原页。
- 原有 21 张扫描图收在可展开的教学参考图里。轮廓与底图均为本地矢量数据，详情和出处见 [地图来源](territory-SOURCES.md)。

朝代与阶段、版图对照、历史专题可分别折叠。侧栏默认居右，可移到左侧并在当前浏览器记忆。当前阶段的观察题和史料留在地图下方。

## 历史人物馆

首批 24 位人物分为帝王将相、科学家、文学家、艺术家四类，每类 6 位，包括中国与世界人物。身份是浏览入口，不排除人物跨领域活动。24 个决策与创作选择案例均按「背景—讨论问题—实际做法—影响—材料局限」展开，讨论题不伪装成人物当时的原话或心理。

关系分为任职、交往、学术承接、后世书写推重、同代背景与主题比较。实线只表示前两类，虚线不表示见过面或直接师承。关系图每次围绕一人，宽列环绕展开，窄列向下展开，无需横向拖动；图下完整说明和出处始终可读。点关联人物可继续展开，跨出当前筛选时清空筛选。名片和人物目录使用右侧栏，可切换左右并保存位置。

`people.html?view=network&person=li-bai` 可分享关系网，`person.html?person=li-bai#decisions` 可直达决策。人物的 `eventIds` 连接已有大事，相关事件页反向提供人物入口；所有人物都可按代表年份返回中外时间轴。人物日期不详时保留 `null` 与显示说明，不用假定年份填满生平。图像、署名及关系依据见 [人物馆资料说明](people-SOURCES.md)。

## 中国古代科技

首批 12 个档案覆盖四大发明、天文历法、数学、医学与本草、水利、建筑六类。每篇保留原理、分步解释、实物或文献线索、材料局限、影响、辨误和讨论题。人物与事件用稳定 ID 双向关联；代表年代是定位入口，不作为唯一发明年。

三个原理演示支持手动操作与网址恢复：`technology.html?topic=printing&mode=type&stage=2` 观察镜像印面与正向纸面；`technology.html?topic=pi&sides=96#principle` 观察内接、外切周长界限；`technology.html?topic=dujiangyan&water=high#principle` 对照丰水与枯水情境。割圆模型用现代三角函数计算，不冒充祖冲之失传算法的复原；水利图只表示部件联系，不提供实测流量、固定分水比例或现状地图。

8 张新增图片在 `assets/ancient-science/`，另有 5 项复用已有事件与人物图像的主出处，图注区分实物、拓片、模型与后世纪念像。详见[科技资料与素材说明](ancient-science-SOURCES.md)。科技首页、档案与演示适应宽屏和竖屏，目录默认在右，可切换左右并保存。

## 丝绸之路

两类路网、7 条代表性分支、12 座城市、6 类贸易品与 4 组文化交流，维护在 `silk-road-data.js`。地图支持选城、前后浏览、聚焦与全览；侧栏路线同时筛选地图、商品与交流，关键词只筛城市目录。`silk-road.html?route=sea&city=quanzhou#route-map` 可恢复路线与城市，`silk-city.html?city=quanzhou#city-evidence` 直达材料部分。目录与档案默认在右侧，可切换左右并记忆。

直接复用历史精讲 `hu5-3` 的定义、稳定 ID、录音与文字稿，以及既有宝船模型与航海图；精讲、人物与事件提供反向入口。4 张新增图像含出处，路线注明年代与概略性质，不把目录顺序当作一趟航行。自然底图由项目内保存的 Natural Earth 输入生成，没有在线地图依赖。详细维护、素材和证据边界见[丝路资料说明](silk-road-SOURCES.md)。

## 数据与链接

文明巡礼共 8 站、32 个知识站、16 项图像材料。`civilizations-data.js` 是正文、主题、观察问题、年代与事件关联的主出处；11 张新增图片放在 `assets/civilizations/`，其余 5 项用 `mediaEvent` 复用已有事件素材与元数据。详见[文明巡礼资料说明](civilizations-SOURCES.md)。

比较深链接示例为 `civilizations.html?view=compare&left=egypt&right=maya&theme=writing`；同一文明被选到另一侧时交换对象，始终保留两个不同文明。主题在宽屏左右配对、窄列上下配对。档案的 `#station-maya-writing` 可直接定位文字站。年代均为选读窗口，不能理解为文化精确的诞生与消失日期。相关事件页反向提供文明入口，保留原事件编号与正文。

- 事件用 `tc数字`（中国轨）或 `tw数字`（世界轨）作为稳定 id，`era` 指向所在时代，`year` 用于显示，`sort` 用于排序。公元前年份记负数，长时段取代表年代。正文、标签、标题和图标由各页直接复用。
- 事件链接采用 `event.html?event=事件id`，总轴定位用 `timeline.html#card-事件id` 或 `timeline.html#era-时代id`，时代站也支持 `#card-事件id`。已有 id 供书签和页面互链使用。
- 素材条目包含标题、图注、观察或听读提示、署名、授权和原始出处。图片还要填写实际宽高和替代文字。音频用 MP3，媒体文件放在 `assets/history/`，出处和延伸资料使用 HTTPS 链接。
- 每组对照的 `china` 和 `world` 分别指向两条轨道、同属一个时代。对照允许一定年代差，测试将差值限定在 350 年以内。
- 朝代带的 `era` 指向与其建立阶段相关的时代站。速览和更替页共用同一个 `id`、`name`、`span`、`startYear` 与 `endYear` 等字段。深链接采用 `dynasties.html#dyn-朝代id`，更替桥的 `from` 与 `to` 连接相邻的两个朝代带。
- 年代用通行约数，传说明确标注，数据字符串使用中文标点。增改数据后运行下方校验。
