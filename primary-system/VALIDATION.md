## 接龙提示 403 修复（2026-10-31）

- 症状：游客点提示无反应。根因双重——重写对局模板时 `{% csrf_token %}` 丢失（页面不种 CSRF cookie、POST 全线 403），且前端把非 JSON 的 403 响应吞成「没反应」；测试未抓到是因为 test client 默认关闭 CSRF 校验。
