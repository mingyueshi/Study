# 地理资料维护

国家与地区的原始、派生记录均完整保存。导入按照固定来源版本及行代码校验实际字段内容；`editorial_name_zh` 和 `notes` 属人工字段，重跑不覆盖。资料仅在整个事务成功、逐行核验完成后公开。

页面使用中文区域及短名对照，保留来源原文。`chinese_names.py` 的首都表为人工整理的常用译名；247种来源首都名称中246种有中文对照，`The Bottom` 暂缺，不自动音译。

语言和货币中文对照冻结在 `language_currency_zh.json`。来源是本机 Node.js `Intl.DisplayNames` 的简体中文 CLDR 48.0 / ICU 78.3，再补充常见名称。语言153种中152种有中文对照；`kwn` 暂缺。货币160种均有中文对照。来源自定义货币代码并非全部属于ISO 4217。对照不改变任何来源字段，也不构成国家地位、首都或边界认定。

运行不依赖Node、Babel、资料包或 `references/output`；静态对照随代码发布。地图边界尚未提供。已知来源异常（如香港首都字段、梵蒂冈联合国成员字段、中国面积）保持原值；儿童页面明确标为来源值，详细来源审计见项目维护文档。
