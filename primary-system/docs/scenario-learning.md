# 场景词卡学习对象（2026-11-02）

本阶段仅修改 words 领域。共享账号、词库不复制；教材和未来独立学科不套用本领域进度。

## 模型与学习语义

LearningTarget 使用 UUID，表示一张教学词卡的掌握目标，能力固定为 card（词卡掌握，非全词／拼写／听辨能力）。目标固定选用 Sense、可选 Pronunciation、SourceRecord 证据，保留原证据及迁移映射。目标身份不由拼写决定，创建后不可换义或换证据；改变教学语义需创建新目标，原进度不转移。

ScenarioWord 保持旧主键，成为场景编排，按 scenario + target 唯一，允许同形不同义。教学标注、顺序、导入基线在词位，人工修改优先。删除词位不删除目标和进度。WordProgress 按账号或游客 + target 唯一，保留旧词位追溯编号、主键、learned、更新时间；不合并游客与账号。revision=0 表示首次写入，之后严格比较版本，冲突返回409；同目标行锁串行首写，数据库唯一约束兜底。SQLite 使用 IMMEDIATE 事务。

## 迁移映射

新增 words.0003 正式迁移，从每条旧词位创建独立 UUID 目标，不按拼写去重。仅当原 entry 在 primary-words 生效来源中恰有一条证据时关联；多条或缺失保留待复核目标与旧 entry/词位快照，不猜选。旧进度逐条更新 target 和 legacy_word_id，其他字段不改。随后新增 words.0004 固定迁移时人工修订快照；不改写已应用的0003。迁移只能保留旧词卡的掌握声明，不反推旧学习时间点尚未留证的历史词义版本。目标外键 PROTECT，进度中的旧词位 SET_NULL。旧 entry 外键作为历史兼容字段保留，展示通过目标选定的 sense 读取，不再使用旧 entry 查询释义。后续导入可显式指定 target UUID；无显式选择时只接受恰好一条生效证据，多义项必须指定 evidence_id 或 target_id。

## 来源与修订

展示只从目标选定 binding、义项、读音读取，且当前来源启用、版本就绪、词条未停用、当前 lexical_hash 与固定证据一致。变义、删词、停用暂不显示释义与音标，保留目标、标注及掌握，提供待复核状态；回退原语义自动恢复。词条归并移动 Sense/Pronunciation，目标跟随稳定义项身份，不依赖旧 entry。目标还固定选用时的人工释义／读音值及 revision。人工修订变化同样暂停释义／音标并提示待复核，必须显式创建并选用新目标；原目标、修订快照和进度保留，不推断旧掌握覆盖新修订。关联词存在多个目标时不按拼写选义，也不从拓展表绕过停用来源。

## 导入与接口

预演运行同一事务逻辑后回滚，报告新增／保留／歧义／冲突。重跑不删除缺失场景或词位，不重绑已有目标；既有标注和场景字段一律保留；新增标注另存导入基线，后续内容修改由后台维护，不用重导覆盖。API schema_version=3，词位 id 只用于布局；写入要求 target_id + revision + schema_version + chinese_version_id + presentation_revision，旧请求返回409要求刷新。前端成功后同步更新所有共享目标的词卡。

## 中文呈现衔接

中文版本独立于Sense人工字段，目标明确采用固定版本，保留采用历史。中文同义修改只允许从当前版本直接到已核对的同义下一版；改义须新目标，旧目标的永久已有语义标记不因删除编排／进度而重置。来源与人工快照校验仍先于中文正文，中文不能绕过停用或变义。

WordProgress新所见字段保留历史null；新写入必须携带孩子实际看到的中文UUID（legacy为null）及采用revision。旧页与采用竞争被拒绝或保留其真实旧呈现，不补最新版。schema2浏览器须刷新。未采用中文的既有卡继续固定legacy来源呈现，不算已完成中文版本审校。见 [中文实施报告](chinese-sense-implementation.md)。
