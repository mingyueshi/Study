# 学习动效与描红

本轮在现有笔顺页与数学挑战练习中增强交互，不恢复已退役的 arithmetic 应用，不改题库批次、笔顺来源或积分规则。

## 统一反馈

- 页头「动效与声音」提供跟随系统、轻柔、关闭动效。偏好键为 `study_effects_v1`，只保存在当前浏览器；存储不可用时仍可在当前页面操作。默认跟随系统，音效默认关闭，系统的减少动态效果设置始终优先。
- `static/study-effects.js` 在 base 模板中初始化；CSS 统一限制装饰动画。新 JS 动效通过 `StudyEffects.motion` 及 `study:effects-change` 判断、响应偏好，不依赖 CSS 去停止 JS 播放循环。
- `StudyEffects.celebrate({key, target})` 在完成结果显示后调用，同页同 key 最多触发一次。撒花库首次需要时才从本地 static 加载；轻柔／关闭模式不加载撒花库。失败不影响结果、错题本或重练。
- `StudyEffects.watch(element, pause)` 用于教学组件离屏和页面进入后台时暂停，返回取消监听的函数；返回前台不自动续播。新组件应在卸载时调用取消监听。已接入汉字写字板、太阳系实验桌、地理路线、迁徙年代地图、历史版图和汉字演变；观察范围包含演示控制与图示，避免控制区可见而图示还在下方时误暂停。
- 科学微粒／电路及天文月相／日月食观察也使用同一套偏好和 `watch`，各自页面同一时刻只运行一个观察演示。
- 音效使用原生 Web Audio 生成短促轻音，无外部音频素材。发声前检查浏览器朗读及页面媒体；`speech.js` 开始朗读和媒体开始播放时停止提示音。关闭音效、切到后台或离开页面也会停止。
- 后续模块应复用此接口和现有 `rewardToast`，不要自己追加第二套偏好、全局音效或撒花脚本。

第三方版本、来源、许可及文件摘要见 [vendor 说明](../static/vendor/README.md)。本轮没有加入构建步骤或运行时外网依赖；离线使用仍需要本地 Django 服务运行。

## 汉字笔顺与描红

入口为 `/hanzi/<汉字>/`，如 `/hanzi/人/`、`/hanzi/学/`。复用当前就绪版本的 `HanziAsset.strokes` 和 `medians`，由 `hanzi/strokes.py` 校验结构，通过 Django `json_script` 安全下发。没有第二份字库、远程字形请求或数据库迁移。

- 静态字形默认可见，支持逐笔显示、重新开始。
- 点击播放笔顺才开始演示，可暂停／继续；减少动态效果时改用逐笔查看。
- 描红支持鼠标和触屏，按原笔顺验证笔画。写错时提示起笔位置和方向，正确时说明下一笔，整字完成后可再描一次。
- 写字板离屏、页面进入后台时暂停，手动继续后接着原进度。切换音效或动效偏好不会清空已描笔画。
- 数据不合格或库加载失败时保留静态字形和逐笔查看；无脚本时保留完整静态字形。
- 本轮描红记录只在页面内存在，不判定书法质量、不产生积分或新的学习档案。来源字形可能有区域差异，保留原来源说明，不将其标成所有教材的唯一写法。

## 数学练习完成反馈

按确认范围接入现有 `/questionbank/practice/?area=math` 及使用同一练习页的数学题组。全部题目成功得到服务端判定、最后点击「看结果」后，显示成绩并庆祝一次；普通单题答对不撒花。自评与客观判分继续分开统计，答错仍进入原错题本。

上报失败不计入完成数量，重试成功后才推进。重复点击不重复庆祝，重新开一组后独立计数。偏好面板内的键盘操作不会触发答题快捷键。
