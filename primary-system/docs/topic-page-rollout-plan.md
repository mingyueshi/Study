# 专题页体验优化分批计划

以 [中国 3D 地形](../content_sources/geo-map/china-3d.html) 和 [3D 地球仪](../content_sources/geo-map/world-3d.html) 为样板。打开专题时，先看到要观察的地图、图表或正文。选中一个任务后，在原处看到与它相关的结果，能继续操作或回到总览。

范围先覆盖乐学堂。专题生成器登记了 53 个具名模板，另外还有四组独立课程数据和由各应用提供的专题页面。每批从 [专题生成器](../scripts/build_study_topics.py)、[学习广场入口注册表](../catalog/entry_registry.py) 和对应应用的路由核对实际入口。同一动态模板下的详情页按代表性状态验收。已符合规则的页面记录复查结果即可。

## 可以复用的做法

| 场景 | 页面处理 |
| --- | --- |
| 地图、实验等交互专题的页头 | 将标题和一句观察提示放到工作区上方，横跨主区与侧栏。适合用背景图时，复用与主题相关的本地素材，保留署名，确保三种主题下标题清晰。页头与面包屑之间省去多余分割线。 |
| 多组工具和相关专题 | 把图层、视角、任务入口等集中到可折叠侧栏，按动作分组，首屏优先露出常用项。跨页链接放到「相关专题」等明确的分组，保留链接视觉与焦点样式。用文字和状态同时表达单选、开关与折叠。桌面默认字号下，交互标签优先用 16px，常用触控按钮的点击区域至少 44 × 44 CSS px。 |
| 选中后的主区 | 地点档案、实验结果、回放讲解、挑战题干与反馈随当前选择显示。切换后收起上一个任务的内容。图例、缩放、回放滑杆、作答区等与当前观察紧密关联的控件留在对应内容旁。 |
| 侧栏展开和滚动 | 复用共用侧栏的左右切换与折叠偏好。桌面默认居右，窄屏使用原有折叠规则。侧栏随内容和窗口可用高度布局，超出时才局部滚动。顶部页头移出屏幕后，侧栏能利用释放的空间。 |
| 阅读、索引和练习 | 阅读页直接展示正文，目录或筛选可折叠。专题索引优先让入口、搜索和分类易找。练习设置可侧置，题干、输入、提交和反馈保持在同一阅读顺序。已有清楚布局的专题沿用现有结构。 |

侧栏优先按 [阅读侧栏布局](sidebar-layout.md) 接入，同时复用阅读偏好和折叠样式。先在同一模板家族内验证重复需求。确需调整共用组件时，保留既有页面的行为，并回归其代表性入口。

## 批次顺序

每批先完成一组共享骨架的页面，通常为 2–4 个入口。验收后再扩到同类页面。同一批涉及多组骨架时，按下表顺序拆开交付。

| 批次 | 优先页面 | 做到什么程度 |
| --- | --- | --- |
| **1 · 平面地图试点** | 中国地图、世界地图 | 跑通图层、找地点、地点档案、地图挑战以及河流回放或邻国探索。确定工具分组、显示优先级、窄屏顺序和返回总览的交互。 |
| **2 · 地图专题** | 先中国动物、植物地图，再世界动物、植物地图。随后检查图谱首页、省域站、发现地点、路线和图集 | 前两组共用地图工具组织方式。选中物种或地点后，地图旁呈现档案。图谱首页保留易扫描的入口，详情页保留自己的筛选、路线和图文阅读节奏。 |
| **3 · 地理实验** | 先板块、比例尺、等高线和剖面，再按海洋与气候分组检查洋流、潮汐、天气和中国气候 | 把视角、变量和实验切换放在侧边，保留图内的指示、读数和拖动控件。用典型任务验证播放暂停、参数变化和重置。 |
| **4 · 跨学科演示** | 历史疆域、天文探索、科学实验室、人体奥秘站分开推进 | 每个专题先选一个有代表性的交互作为样例。分别验收时间轴、演示控制、实验变量或人体图示与说明的联动，再覆盖同专题的其他入口。 |
| **5 · 阅读与资料专题** | 先历史双轨时间轴、时代与事件页，再依次推进人类起源、文学常识、汉字演变馆、古文精读馆和成语典故馆 | 核对目录层级、当前阅读位置、关联入口和字号变化。保留正文、注释、音频及已有学习记录。章节与详情能通过原链接直达。 |
| **6 · 练习与独立专题收尾** | 题库、词树、图形运动实验室及前几批核对出的剩余专题 | 先保护练习进度、输入状态和搜索结果，再处理影响操作的布局问题。每个独立专题按现有学习流程确认调整范围。 |

## 首批实施清单

1. **从真实入口记下现状。** 从学习广场和地理图谱打开 `/geography/atlas/china.html` 与 `/geography/atlas/world.html`。记录默认图层、主要工具的位置、地点档案状态、桌面与窄屏首屏。补测两张 3D 页已有的平面地图入口，以及 `china.html?place=f20#map` 定位。
2. **先整理两页共有工具。** 侧栏分出图层与定位、探索玩法、相关专题。地图保留缩放、图例与当前任务的结果和控件。页首保留地图标题和必要提示。口诀卡与地理对照卡仍按阅读顺序放在工作区下方。
3. **完成各页一条完整流程。** 中国地图从选择河流到播放、暂停、拖动进度和切回省份档案。世界地图从选大洲到查看档案，再切换陆上邻国和隔海相望。两页各做一轮「找一找」，检查进入、答题、完成和退出后的显示。
4. **复查联动与旧链接。** 检查图层、侧栏、当前面板与焦点是否一致。验证原链接的查询参数、锚点、刷新和浏览器返回。指向折叠区的有效锚点能展开所在区，地图定位后的档案能直接看到。

## 每批验收

- **布局和主题。** 实测桌面常用宽度、宽屏、390 px 窄屏与矮窗口，抽查较大字号。检查侧栏左右切换、折叠后主区扩展、展开后焦点恢复、长侧栏自然滚动。亮色、暖色、深色下同时检查地图或图示、文字和选中状态，尤其是标签或浮层覆盖图面的地方。
- **已有入口和数据。** 从学习广场及专题内链接打开，覆盖老参数、锚点、刷新和返回。检查原有学习记录、任务状态和浏览器偏好。原本可离线的功能从独立入口验证。涉及 3D 或动画的页面检查已有的降级路径和减少动效设置。
- **源码、生成物和回归。** 从内容源修改并重新生成受影响的产物。在 `primary-system` 执行 `make test-frontend` 并运行对应的 Django 路由和页面测试。涉及专题生成时运行 `.venv/bin/python scripts/build_study_topics.py --check`，涉及数据源时运行 `make test-content-sources`。改动共用组件时，再用浏览器抽验教材侧栏、已有 3D 专题和阅读类入口。具体环境见 [本地开发与数据准备](local-development.md)。
- **交付记录。** 每批记下已检查的入口、改动与保留理由、实际运行的用例及结果。发现问题在本批修复并重测，验收完成后按范围单独提交。下一批沿用已经通过验收的规则。
