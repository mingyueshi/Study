## 审核边界

- 883是两类引用数量，另算学习目标、唯一固定绑定及来源交集；同拼写不代表同义项，同义项也不能忽略读音、证据和修订快照。
- 缺口区分缺少中文正文、已有中文待核对、绑定失效／歧义、已确认已采用。已有中文不重复视作缺失，也不自动升级为已审校。
- 第一批逐条核对源义项、现有中文与候选解释，记录选择原因和未纳入原因。同义更新不扩大学习含义；原数据疑似错义、错读音时先排除，不改旧身份来凑批次数。
- 生成与复核身份如实记录。AI复核不冒称用户或真人审核；确认状态表达本批明确检查结果，不代表全词库质量保证。
- 日常库只采用主控审核过的固定文件；文件摘要、绑定、内容或采用范围变化后必须重新核对。内部设计复核不另要求用户审批。

## 验收条件

1. 全量清点可复跑，分类互斥、合计准确；每条引用可定位，缺口与排除原因可追踪。
2. 首批中文逐条对齐固定源义项，儿童可读；英文学习词形及原文保留，中文不塞入英文Sense修订字段。
3. 批次有稳定身份和内容摘要；dry-run零写入，重复执行零新增，部分冲突整批不写，重跑不覆盖人工改选／恢复撤回版本。
4. 写入复用中文版本、核对和采用服务，带准确的所见revision；并发首导及来源变化不能绕过选择保护。
5. 采用不制造学习记录；旧页面提交冲突，既有私人记录及历史所见版本保留，同形异义不串联。
6. 先隔离副本，再新恢复点和日常正式批次；独立核对原字段与新增数据白名单。
7. 桌面和390px核验真实首批中文、教材关联、搜索及学习保存；测试账号／进度不写入日常库。
8. 最终报告分别列出已采用引用数、唯一绑定数、剩余中文缺口和待核对项。保留备份与证据，清理临时验收资源，不提交／推送／部署。
