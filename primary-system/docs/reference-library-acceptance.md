## 核验重点

1. 9包摘要／CRC／文件清单一致，分包重复文件有明确归属；每个数据集的源数、导入数、排除数和可见数对应。
2. 来源固定身份及快照可追溯，记录不因词形、大小写、Unicode归一或相同读音而丢失；重复导入不重复或覆盖人工字段。
3. dry-run不写数据库或资产；按数据集事务导入，失败后可安全重跑，未完成数据不伪装就绪；空库及旧库可正式迁移。
4. 首页与各学科入口可达；中文列表／搜索／筛选／分页／详情有可读字段，不能只显示JSON。英文原文与翻译状态诚实标示。
5. 科学答案和教师层按嵌套祖先完整分离；源码、API、搜索、打印、原文及教师独占图片不能向学生泄漏。普通登录不等于维护权限。
6. 全量查询使用数据库过滤／分页，不在请求中反序列化十万条数据；记录完整导入耗时、库体积及代表性页面查询规模。
7. 桌面和390px真实浏览器覆盖各领域、汉字逐笔、科学图片与角色权限；既有词卡、教材、词典、接龙继续工作。
8. 导入不新增学习记录、自动课程映射或完整中文审校结论。保留原始包、恢复点和验证报告；清理本轮临时测试资源，代码不提交／推送／部署。
