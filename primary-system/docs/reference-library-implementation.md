## 导入、权限与回滚边界

```sh
.venv/bin/python manage.py import_reference_library --dry-run
.venv/bin/python manage.py import_reference_library
```

默认输入为项目父目录references；可用`--input-root`明确指定。dry-run会临时解压到系统scratch并清除，完整预检来源、已有登记、已有资产、版本摘要、就绪数量及逐行来源字段，不写数据库或项目资产。正式运行按数据集事务导入、锁后复核，完成才ready；相同来源重跑零新增。来源字段漂移、孤立记录或缺行会拒绝，不静默覆盖；指定人工字段（如CEDICT matched_sense、国家人工名和备注）保留。共享文件使用每次唯一临时文件后原子替换，避免并发rename争用。

原始EPUB/XML、答案、教师节点始终保存在私有层。DOM教师祖先权限继承；章节归属取最近section祖先；表格保留空格、行列和合并。学生页仅从清洗过的类型化block构建正文与搜索，教师文本没有进入学生HTML、搜索、打印或通用旧API。图片需签名且学生可见，签名不能把私有图变公开。教师/原文下载要求active staff及明确的ScienceBook维护权限；普通登录、旧默认view权限和单独staff均不能放行。

有意保留的日常导入前备份：`Study/output/reference-library-implementation/daily-before-reference-20261102.sqlite3`（313MiB，0600）。原有备份不动。不能以删除数据集表或覆盖人工内容作为升级方式；恢复时应停本地服务、核实备份，再由维护者明确执行恢复。当前没有生产迁移、提交、推送或部署。
