原则先行

六条设计原则

所有界面改动前先对照这一节，每条都配「这样做 ✓」与「避免 ✗」

🎈 活泼有童趣

读者是小学生和家长，界面要明快、像一本精心排版的童书，而不是一个后台。

  • 配色鲜明不沉闷，圆角卡片 + 色块 + 图标
  • hover 有轻微上浮、阴影等轻量动效
  • 用 📚 ✏️ 一类装饰气泡营造氛围
  • 灰底表格式的严肃后台排版
  • 大面积高饱和色块刺激眼睛

🔍 大字号易读

正文 18px 起、行距 1.7 起，孩子和家长长时间阅读都不费力。

  • 标题层级醒目，h1 用 clamp 随屏幕放大
  • 拼音、读音、答案等重点内容再放大或加粗
  • 说明文字可用 14–16px，但不做主信息
  • 14px 以下的正文长段落
  • 行距压到 1.5 以下省空间

🖥 桌面端优先

按宽屏（横屏）和竖屏的阅读体验设计布局、间距与字号。

  • 1680px 起加栏展示更多内容
  • 1199px 以下逐步减栏，599px 以下单列
  • 间距用 clamp() 随视口伸缩
  • 为移动端做专门的花哨适配
  • 移动端布局反过来挤压桌面端体验

🌱 长在 Token 上

颜色、字号、圆角、间距只有一份定义，改一处全站生效。

  • 新页面一律引用本文档列出的变量
  • 学科色用现成的三色组（tint / line / accent）
  • 确实需要新 Token 时，先进本文档再上代码
  • 临时写一个「就这一次」的魔法色号
  • 同一含义出现两种相近颜色

🎯 焦点看得见

孩子用键盘、家长用鼠标，都要随时知道「我现在在哪」。

  • 键盘焦点用 3px 橙色焦点环 var(--orange)
  • 按钮带 3px 底部投影，按下时下沉 2px
  • 导航、链接 hover 有底色或下划线反馈
  • 用 outline: none 去掉焦点环
  • 点击后毫无视觉反馈的死按钮

🌊 动效要克制

动效是调味料，只用来引导注意力，不抢内容的戏。

  • 时长控制在 0.2–0.3 秒的轻量过渡
  • 尊重 prefers-reduced-motion，用户要求减少动效就降级
  • 打印样式里去掉装饰，只留内容
  • 闪烁、弹跳等容易引起不适的效果
  • 为了炫技延迟内容出现

SPACING · LAYOUT

间距与栅格

页面留白跟着视口走，宽屏也不散

页面留白

左右页边距 --gutter: clamp(20px, 3vw, 80px)，窄屏收到 18px；内容最大宽 --page-width: 2240px。

卡片内距

模块卡 28px，阅读器 clamp(28px, 3vw, 56px)，hero clamp(32px, 3.5vw, 64px)；小屏统一减到 22–24px。

栅格

模块卡默认 4 列（≥1680px 变 6 列），书卡 3 列；卡间距 22px，区块之间 56–64px。

MOTION · A11Y

动效与可访问

轻快但不打扰

统一动效节奏

过渡时长 .12s – .18s，缓动 ease。卡片 hover 上浮 translateY(-5px) + 阴影，按钮按下下沉 2px。

尊重系统设置

prefers-reduced-motion: reduce 时关闭滚动动画、上浮与缩放，只保留颜色过渡。

可读性兜底

深字浅底为主，正文与背景对比度均 ≥ 4.5:1；overflow-wrap: anywhere 防长单词撑破卡片；打印样式单独适配（隐藏导航与按钮）。
