# 中国地形视觉深化验证

入口：`/geography/atlas/china-3d.html`。日期：2026-11-16。

## 实现

- 每 500 米一档的等高线直接沿现有三角网插值，保留网格本身在鞍部的连接关系。默认关闭，打开后按省分帧生成；详细 DEM 替换时局部重建，弱引用缓存跟随原块释放。
- 光照提供东、南、西、北及西南预设、方位角滑块和指南圈，改变迎光坡与背光坡的明暗。没有增加投射阴影贴图，不表示实时太阳方位。
- 雪线滑块范围 0—9000 米，100 米一档，默认 5000 米；拖动自动开启，原按钮可关闭。着色器从独立的原海拔属性插值，动态更新共享阈值，保留三种地图配色。白色为高度观察示意，不直接代表永久积雪。
- 14 个山脉名称加微型图标，沿用原名称、位置和稳定 ID。
- 地形不透明度为 0—100％；半透明时关闭表面与侧面的深度写入，恢复 100％时恢复，省界继续清晰显示。河线、湖面和等高线可继续对照，射线定位与海拔不变。
- 工具放在既有右侧独立滚动栏，调节时可同时看地图，沿用侧栏左右切换与窄屏抽屉。

算法、参数和边界见 [TERRAIN-VISUAL-SOURCES.md](../../content_sources/geo-map/TERRAIN-VISUAL-SOURCES.md)。没有改写原始 DEM、河线或烘焙数据。
