# 《道德经》精读验收

## 范围

- 新增 `/classical/books/daodejing/`，上篇道经三十七章，下篇德经四十四章；每章一个结构化 JSON 和独立精读页，编号 `daodejing-01` 至 `daodejing-81`。
- 八十一章正文依本机简体《老子》底本，分为 428 句；每句包含译文、词义、停顿与背诵关键词，部分另有语境提示和明确指代。第十一章三个「其无」分别指向轮毂、器皿和房屋的空处。
- 每章两道选择、一题讲述自查，共新增 243 道练习。全馆现在有 10 篇精选、两部全书，合计 111 个阅读页、983 个精读段、343 道练习。
- 已接入古文馆首页、专题导航和语文专题介绍。全书目录支持分卷跳转、原文／译文／词义搜索与搜索分页；详情提供逐句与全文朗读、语速重复、遮挡背诵、即时判题、本机标记和四种整章打印，以及单句原文／讲解打印。
- 扩展并校验全书 `part_label` 与 `landmarks`，目录模板按篇／章、句／则呈现，不复用《论语》的固定标题和单位。无新数据库字段、迁移或运行时网络依赖。

## 内容与来源

- 来源版本、路径、指纹和章节锚点见 `content_sources/classical/daodejing/README.md`。原典定位全部只读核对：81 个整章与 428 个句子锚点均匹配本机原典。
- 原文统一引号，第七章将括号异文提示移出精读正文，仍保留在原典锚点。第十八章按四个分号分句分别配译；其余按句末标点分句。校验逐章句数与有序汉字指纹，测试将句子拼回底本，防止漏句或改字。
- 译文、词义和练习为本馆编写的入门读法，理解时参考公开的王弼注。原文依本机底本保留，不把王弼本与本机版本暗中混用。
- 明确「无为」不等于不做事、「自然」在部分语境中是自然而然、「病」在第七十一章是毛病等词义。古代治理、鬼神、长生及婴儿的理想化描写另作语境提醒，不当作今天的教育要求或现实保证。
- 人工复核分句与译文对应，修正第十五、二十章问号前带分号导致的译文对应问题，并增加回归检查。合并前后对照，原有 30 个阅读页面的内容指纹保持一致，旧学习标记与《论语六则》的兼容跳转继续有效。
