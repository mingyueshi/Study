# 地球仪互动与主题图层验证

入口：`/geography/atlas/world-3d.html`。日期：2026-11-16。

## 功能

- 原两条历史航线保留分段大圆弧与站点时钟，增加可见船只、到站提示及画面内的「镜头跟船」开关。匀速按球面里程推进，手动操作、离屏、后台和减少动态时暂停。
- 多点行程可命名、保存、打开、编辑、删除和回放。最多保存 8 趟，每趟 2—20 站；恢复时校验坐标和名称、重新计算里程，存储失败保留本页并提示。
- 寻宝与地理侦探各提供前 5 处计时挑战。主动开始、本轮去重，历史记录不自动计分；暂停继续累计，切换玩法或后台暂停；查看答案后转为练习。切换玩法时不显示上一玩法的完成成绩。
- 新增 18 城人口规模圆点、六大板块教学分组、约 2 亿年前古陆拼图、亚洲冬夏季风、台风转向示意、NASA 多年平均年降水和四个星座的示意天球。星空背景独立开关，天球连接原天文探索。
- 古陆视图收起现代标签、档案、起伏、灯光和航线；返回现代或打开其他玩法时恢复。古陆名称使用清晰的屏幕标签，避免贴图缩小后字太小。
- 倾斜控制仅点击后请求权限，先校准，横竖屏转换、离屏、后台、手动操作或换玩法时关闭。拒绝授权、无传感器或非安全连接都有反馈。

数据来源、时间、分组、取样方法、输入指纹及示意边界详见 [WORLD-LAB-SOURCES.md](../../content_sources/geo-map/WORLD-LAB-SOURCES.md)。

## 工程

既有专题生成命令按有序清单生成并保存合并脚本，专题脚本由原 27 个请求降为 3 个；不增加打开页面时的构建或联网要求。独立源文件继续维护、测试，生成检查同时校验源目录与发布目录的合并文件。

纹理增加内容键。镜头转动、船只移动及太阳单步时，浏览器观察到 `data-texture-paints` 不增加；切换主题图层或选中内容时才重画。该检查证明避免重复绘制，不作为固定启动时间或帧率提升的承诺。

- 世界图层结构、原世界地球仪内容、历史航线与时区源测试通过；地理图谱 6366 项检查通过。
- `make test-frontend`：254 项通过，含新增旅行存储校验、计时去重／冻结／失效、人口圆面积比例、倾斜轴变换、跨日期线及对跖点匀速采样等 6 项测试。
- `manage.py test catalog.test_study_topics`：11 项通过。
- `build_study_topics.py --check`：864 个发布文件，0 差异；`git diff --check` 通过。
- 浏览器逐层检查人口、板块、古陆、冬夏季风、台风、年降水与天球，图层切换与现代恢复正常；人口城市可定位并读数，古陆显示 7 个屏幕标签。
- 旅行两站累计约 10990 千米，保存后刷新可打开并回放；取消镜头跟随后，船只位置持续变化且纹理重绘计数不变；键盘操作暂停航行。
- 两种计时挑战均可独立完成 5 处并显示耗时；看答案使本轮转为练习，暂停后数值冻结，切换玩法不会显示上轮成绩。
- 模拟设备事件验证：未点击不请求权限；拒绝后保留拖动；授权后首次姿态校准，后续倾斜移动镜头但不重画纹理，手动转动会关闭。
- 禁用 WebGL 并禁止写入存储：人口文字仍可查看，行程可编辑、保存失败有提示，回放按钮不可用，坐标寻宝和计时仍能使用，无页面脚本异常。
- 390、820、1920、3440 像素窗口无横向溢出。
