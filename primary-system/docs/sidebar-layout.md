# 阅读侧栏布局

正文与目录、筛选或辅助资料组成左右布局时，统一默认右侧，通过顶部按钮切换左右，选择沿用教材与场景页的浏览器位置偏好。目录使用窗口剩余高度，搜索、筛选和进度等固定工具可以置于目录上方。窄屏提供展开／收起入口，打印时隐藏侧栏。

人类起源学习站的考察路线放在侧边，默认右侧并可左右切换。宽屏支持收起为窄导航条，收起后正文使用腾出的宽度，可点击「展开导航」恢复；折叠状态在五个学习站之间保留。小于 900 像素时导航放到上方并默认收起。正文内部仍为单列，迁徙地图与年代说明上下排列。

此前完成的英语教材、场景单词和场景成语继续使用原有播放器与侧栏，并共享位置偏好。双栏正文、概念对照、地图内浮动地点卡、示意图与编辑预览按原有内容编排呈现。

## 接入与维护

共用资源在 `static/sidebar-layout.js` 与 `static/sidebar-layout.css`，由 `base.html` 加载。注册表明确指定布局容器、直接子级侧栏、适合阅读的宽度、切换为窄屏的宽度和需要固定在上方的工具；生成页面使用注册表接入，无须修改生成物。

新页面也可以声明 `data-sidebar-layout=".my-sidebar"`，通过 `data-sidebar-width`、`data-sidebar-breakpoint` 和 `data-sidebar-fixed` 指定宽度、窄屏断点和固定工具选择器。侧栏与正文须为该容器的直接子级。组件只移动已有 DOM 节点，保留事件与表单值；动态生成或替换的侧栏会自动接入。节点移除时释放尺寸监听。

需要宽屏折叠时，增加 `data-sidebar-collapsible="true"`。可用 `data-sidebar-collapse-key` 指定浏览器内的折叠状态存储键，并用 `data-sidebar-label` 指定按钮中的名称；未启用的页面继续使用原有侧栏操作。宽屏折叠与窄屏展开状态相互独立，调整窗口后保留宽屏偏好。

个人学习系统维护自己目录内的独立实现与偏好，不引用小学系统。验证时检查首页、详情、带参数深链接，以及左右切换后的目录滚动与输入状态，覆盖约 390、820、1920 和 3440 像素宽度。
