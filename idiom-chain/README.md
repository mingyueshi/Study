# 接个成语 · Django 演示

真实 Python 3.12 + Django 6.1.2 + SQLite + Django Admin 项目。所有词库判定、计分、游客对局及记录由 Django 服务端执行并存入 SQLite，不是浏览器模拟后台。

## 本地快速启动（最新版家庭学习版）

需要 **Python 3.12、Git、首次安装时可访问 PyPI/GitHub 的网络**。先解压，进入本目录：

```sh
python3.12 bootstrap.py
```

Windows 可用 `py -3.12 bootstrap.py`。脚本建立本项目 `.venv`、安装固定依赖、迁移、在全新数据库导入自编基础词，再幂等导入完整 chinese-xinhua，最后只监听本机 http://127.0.0.1:8000 。按 Ctrl+C 停止；下次仍运行同一命令。已有对局不删除，后台人工修订受导入锁保护。**不需要 Node/npm。**

只初始化不启动：`python3.12 bootstrap.py --setup-only`。此便捷入口只供本机家庭使用，不是公网部署入口；不会创建管理员。若需管理词库，可另行交互运行 `.venv/bin/python manage.py createsuperuser`（Windows使用 `.venv\Scripts\python.exe`），自设账号密码。

本包包含 **30,895条原始成语** 和固定数据校验；全新库加154条自编词后合计30,901条。此前云端库30,905条包括另外4条保留的旧试用词，本包不携带运行数据库，因此不复制那些历史残留。词典可查非四字，接龙仅使用合格四字词。游客通过Cookie保留本机对局，清除Cookie后不能找回原游客记录。

首次依赖安装失败时按错误检查网络/Git/Python版本，再运行同一命令即可；导入器遇哈希不符会停止，不能擅换数据文件。旧机器已有`.venv`时需确保它也是Python3.12，或将其重命名后重新初始化。

## 游戏与测试

只允许内置精选四字成语，后一词首字必须等于前一词尾字，不接受谐音；同局不得重复。答对 +10 分，提示 -5 分（最低 0）；无候选可重开。刷新保留进度，重开保留最近五局记录。

```sh
.venv/bin/python manage.py test
.venv/bin/python manage.py check
.venv/bin/python manage.py makemigrations --check --dry-run
```

写操作使用 CSRF + 数据库 IMMEDIATE 事务 + round_id/revision 乐观校验，旧请求不会二次计分或跨新局执行。

## 公开部署前提（尚未部署）

需要现有、获授权的 Python 3.12 托管目标，并有持久可写磁盘。Sites 的 Worker/D1 运行环境不等于原生 Django/SQLite，不可把本项目上传为静态站后声称完成。

单实例、小流量演示部署：
1. 安装锁定依赖和目标选择的生产 WSGI 服务（不得使用 runserver 公开运行）。
2. 设置 `DJANGO_PRODUCTION=1`、已有安全配置中的 `DJANGO_SECRET_KEY`（至少50字符）、真实域名 `DJANGO_ALLOWED_HOSTS`、HTTPS源 `DJANGO_CSRF_TRUSTED_ORIGINS`。
3. `SQLITE_PATH` 指向持久卷，文件仅服务账号可访问。不能放在静态目录。多实例共享/临时磁盘不适用。
4. 执行迁移、词库种子和 `collectstatic --noinput`；由反向代理服务 `staticfiles/`。
5. 配置 TLS 和可信代理转发：默认不信任任意 `X-Forwarded-*`。仅在目标代理清洗对应头并经核实后设置 `SECURE_PROXY_SSL_HEADER`。
6. 公开后台须有入口限流（登录及验证码挑战）和访问控制。验证码不替代密码尝试限流。游客 API 也需按来源限流；不将开发版当作抗滥用生产服务。
7. `manage.py check --deploy`；匿名浏览器核真实API、CSRF、SQLite持久重启、后台访问保护后才发布链接。
8. 定期备份 SQLite（使用 SQLite backup API）；执行 `clearsessions`、`prune_slider_captcha`，并按演示保留策略清理历史数据。

本源码不携带部署密钥、不注册新账户、不创建外部仓库。公开链接需真实部署验证后再交付。

## 家庭学习版（不公开发布）

已选择 chinese-xinhua 固定数据版本，保留 SQLite。许可证及抓取来源见 `docs/sources/`；个人使用不意味着可以无条件再发布。数据不含近反义词，不生成补齐。

```sh
.venv/bin/python manage.py migrate
.venv/bin/python manage.py import_xinhua data/chinese-xinhua/idiom.json --report evidence/xinhua-import.json
```

命令验证固定 SHA256，幂等更新、保留自编释义/禁用状态/旧对局；`--dry-run`仅生成报告。不猜测修复异常拼音，格式检查不等于权威读音校勘。非四字可查词典，不加入四字接龙。来源原文“无”属于缺失占位，页面显示未提供。

学习页只按需加载单词详情及每页20条搜索结果。朗读使用设备可用中文合成语音，无中文语音时不可用；不保证多音字正确，不能冒充权威录音。词典数据版本固定，不宣称实时最新或最全。

## v2：完整词典字段，不以简释替代原文

全部30,895条来源记录（包括非四字、读音待核条目）都进入词典，是否允许接龙是独立标记。原始六键为 `word / explanation / pinyin / derivation / example / abbreviation`：

- `source_explanation` 独立存放来源 `explanation` 全文，学习页默认显示它。
- `meaning` 保留此前人工简释/人工修订；重叠的148条自编词不再掩盖原来源释义。自编简释另行展开查看。
- 拼音、出处、例句、首字母均保存到同名字段，页面详情可看；字面“无”在原字段/原始记录中保留，页面按“来源未提供”展示。
- `source_raw` 完整保留原记录，包括未来未知键；来源版本、地址与原记录在后台详情及详情API可查。原始数据只读，不让人工简释或审查状态回写原文。
- 6条自编独有词没有来源记录，明确显示“仅有自编简释，暂无来源补充”。未生成近反义词、故事或新读音。

已有本项目数据库运行同一个启动命令会先迁移，从既有原记录回填完整释义，再进行幂等导入；不清空数据库、不覆盖人工简释、不删除旧局。词条在后台保存后自动锁定，后续导入不会覆盖人工修改；若明确要恢复来源版本，需先解除对应导入保护后再导入。

## 统一学习前端与功能整合（2026-10-30）

前端采用与 `primary` 一致的暖色背景、学科色块、大字号和矢量图标。图标位于本项目 `game/static/game/icons/`，运行时不依赖 `primary`。词典与接龙共用模式导航，桌面使用并排工作区，窄屏自动展开为纵向布局。

当前已接通：

- **词典阅读**：按成语、拼音或精确拼音首字母查询，每页 20 条；支持前后翻词、翻页和键盘方向键。完整来源释义优先展示，保留简释独立展开；出处、例句、来源版本和原始记录均可查看。空值或原文“无”显示缺失状态，不补造内容。
- **阅读与接龙互通**：可从当前成语、接龙足迹和提示打开完整词条，再返回同一局；保留接龙输入和服务端进度。只有当前首字匹配、具备接龙资格且本局未用过的词条，才可填回输入框。填入不自动提交。
- **真实服务端规则**：保留答对 +10、提示 -5（最低 0）、同局不重复、刷新续玩与最近五局记录。页面不会将最近五局之和当作累计成绩或历史最佳。
- **提示与异常恢复**：提示可先查词、再填入、最后手动提交；旧版本冲突会重新读取状态并清除旧提示。网络异常时不会自动重发写请求；对局状态不确定时，先锁定写入并提供重新读取入口。查询乱序不会覆盖新结果，查询失败不会留下旧词条或卡住加载状态。
- **设备朗读**：词典与接龙使用同一套中文合成语音能力，可停止播放；设备没有中文语音时明确禁用。没有权威音频，也不把合成语音当作人工校音。

仅浏览词典不创建对局；首次切换接龙才读取或创建游客对局。`#learn` / `#game` 保留当前模式，接龙进度仍以服务端为准。
