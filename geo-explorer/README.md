# 地理漫游 · 给小小探索家的地球手册

给小学中高年级使用的独立地理启蒙编排。参考 `primary/geo.html` 的八站主题，重新编排37条知识线索，采用“真实画面 → 观察提问 → 动手探究 → 回顾盖章”的学习路径。

## 打开

双击本目录的 `index.html`。无需安装依赖、无需构建，复制整个 `geo-explorer` 文件夹即可带走。图片、短片、知识与互动均保存在本目录；外部拓展影片和来源页面需要联网。朗读取决于浏览器和设备是否有可用中文语音。

也可以在仓库根目录运行：

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

然后打开 [地理漫游](http://127.0.0.1:8767/geo-explorer/)。

## 学习内容

八个探索站：认识地球、方向与地图、地形地貌、天气与气候、江河湖海、我们的祖国、环游世界、生活与地理。保留原37个知识主题的标识，内容按儿童阅读长度重新写作，并核对易错说法。

- **风景观察**：真实照片或卫星影像，支持放大；先描述看见的，再打开解释。
- **地图小侦探**：转动校园地图，跟着北箭头判断方向，观察方向与屏幕位置的区别。
- **水滴旅行**：蒸发、凝结成云、降水与汇入河海，可以逐步操作或开始/暂停动画。
- **四季探究**：切换北半球四个节气位置，观察始终平行的地轴，理解四季与南北半球的差异。
- **地理放映室**：本地历史观测短片与公开机构科普链接，观看前带一个问题。
- **知识口袋与地球护照**：37条知识可全文搜索、按主题筛选；答对题目后收取各站印章。

足迹使用独立的 `geo-explorer-passport-v1` 本地存储键，与历史页分开，不按账号保存，不具备跨设备同步。禁用存储时会提示仅本次有效。

## 布局与文件

沿用 `primary-system` 的2240px宽屏容器、淡绿基础主题、18px正文与大按钮，配合地理专题的浅蓝强调色。900px起为左侧吸顶目录和右侧内容，899px及以下为可折叠目录与内容上下排列。

`platform-theme.css` 是主项目公共主题的本地快照，图标也已复制到本目录；没有对 `primary/`、`history-explorer/` 或 `primary-system/` 的运行时依赖。专题自有样式以 `.geography-topic` 隔离，便于后续放入主项目。

| 文件 | 用途 |
| --- | --- |
| `index.html` | 独立入口与页面结构 |
| `platform-theme.css` | 公共主题快照，仅用于独立页 |
| `styles.css` / `app.js` | 专题样式、观察、搜索、朗读、题目和足迹 |
| `content.js` | 八站37条知识数据 |
| `lab.js` / `lab.css` | 三个地理互动 |
| `media.js` / `assets/` | 本地照片、短片、图标及来源索引 |
| `CONTENT-SOURCES.md` / `MEDIA-SOURCES.md` | 内容依据与素材溯源 |
| `scripts/export_django.py` | 导出只包含专题内容的 Django 模板 |
| `django/explorer.html` | 继承 `base.html` 的生成模板 |
| `INTEGRATION.md` | 以后接入主项目的操作说明 |

## 内容口径

经纬线是定位用的假想线；地图方向优先读指向标。不能只靠树叶、苔藓、年轮辨方向。大洋划分说明我国常见教材四大洋口径与另列南大洋的口径；四季不归因于地日距离。自然照片不代替疆域地图；校园地图、地轴与轨道均标明教学示意。观测短片是过去的观测、经过加速，不是实时天气预报。来源和具体辨识见两份 SOURCES 文档。

## 以后接入

```sh
python3 geo-explorer/scripts/export_django.py
python3 geo-explorer/scripts/export_django.py --check
```

生成的模板不包含独立页头、页脚、`.shell` 或主题快照，正式接入时复用 `primary-system/base.html`。步骤见 [INTEGRATION.md](INTEGRATION.md)。本次不修改主项目应用、数据库、路由或国家地区资料页。
