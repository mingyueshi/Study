# 地理知识精讲

给小学中高年级使用的知识点学习页。37个知识点按八章组织，正文直接展示定义、必须掌握的结论、数据/公式、分类比较、例题、易错辨析与巩固题。图片、图解、动画、音频、视频及外部链接附在对应知识点旁边。

## 打开

双击 `index.html`；也可在仓库根目录启动临时静态服务后访问本目录：

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

打开 [地理知识精讲](http://127.0.0.1:8767/geo-explorer/)。无需安装前端依赖或构建。全部正文、本地图片、图解、动画与讲解音频随目录保存；外部资料需要联网。浏览器逐点朗读取决于设备是否有可用中文语音。

## 编排方式

- 左侧选章，本章全部知识点直接呈现在正文中；二级目录与页内索引可跳到具体知识点。
- 每点包含明确的定义、3—5条具体结论、例题推导、易错辨析和巩固题；适合的条目另设数据、公式和比较表。
- 例题保留题干，推导与答案可展开，便于先独立作答；主要定义与结论不折叠。
- 比例尺、经纬网、五种地形、三级阶梯、天气气候、两河对比、地方时有配套概念图。校园地图旋转、水循环和四季动画由相关知识点打开。
- 比例尺、四季、水循环、地方时有4段本地AAC讲解音频及文字稿；37点均可尝试浏览器中文朗读。
- 卫星云图短片辅助理解天气观测，三条央视影片分别关联云、冰川和梯田；每点有直接的权威机构资料链接。

页面沿用 `primary-system` 的2240px宽屏容器、基础主题、18px正文和左目录布局。899px及以下改单栏，目录默认收起；表格与概念图必要时在内部滚动，避免挤压正文。专题样式限定在 `.geography-topic`。

## 自测记录

逐知识点答对巩固题后，记录到浏览器的 `geo-knowledge-progress-v1`。记录表示该知识点的一次巩固题答对，不能直接等同于全面掌握。记录不按账号同步，禁用本地存储时仅当前页面有效。

旧版 `geo-explorer-passport-v1` 探索印章与新记录分开；本次不删除、不自动换算旧印章。搜索可检索定义、结论、公式、比较表、例题与辨析。

## 以后接入主项目

```sh
python3 geo-explorer/scripts/export_django.py
python3 geo-explorer/scripts/export_django.py --check
```

生成模板继承 `base.html`，不携带独立页头页脚或主题快照。详见 [INTEGRATION.md](INTEGRATION.md)。本目录不读取 `primary/` 或 `history-explorer/` 的运行时资源，不修改主项目路由、数据或已有国家地区资料页。
