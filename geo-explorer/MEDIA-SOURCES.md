## 路径与核验

`media.js` 以相对的 `assets/` 路径记录文件，并在加载时根据 `document.currentScript.src` 转成完整 URL，因此可以在独立 `file://` 页面、静态 HTTP 页面或 Django 深层专题路由中使用同一份数据。

图片经文件类型、像素尺寸检查，并逐张查看画面核对题注；视频为有效 WebM，封面与相同卫星序列对应。所有 `src` 和 `poster` 文件均在本目录内。
