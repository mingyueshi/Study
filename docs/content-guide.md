# 内容编排指南

设计一段学习内容时，可以先问：「学完以后，读者能自己解释什么、判断什么，或做出什么？」同样讲一条河，想弄清它流经哪些城市，一张平面地图就容易读清；想弄清两侧的雨水为何流向不同山谷，转动 3D 地形、找到中间的山脊会更直观。

教材正文和课内练习跟随对应版本、年级、册次与单元，延伸探索与课内要求清楚区分。专题可以从任何年龄都可能提出的问题起步，按需要补足前置知识，一路讲到专业层次。界面和讲解以简体中文为主，外语、引文和术语保留合适的原文。使用史料、数据或模型时，交代出处以及它能支持什么判断。

## 各学科有哪些讲法可借用

下面是备课时可选的思路。每一行的方法都可以借给其他学科，也可以按同一个问题组合使用。讲到空间关系、内部结构或运动过程时，尽量用可交互的 3D 演示，让旋转、剖开或换视角的操作回答一个具体问题。

| 领域 | 可借用的讲法 | 一个可以动手或动脑的问题 |
|---|---|---|
| 地理 | 用地图读位置和分布，用 3D 看地形起伏。 | 在平面图上找到两条河，再转动地形看它们之间的山脊。雨落在山脊两侧，各会流向哪里？ |
| 历史 | 用时间轴串起先后与同时，用史料追问原因。 | 把一座城修码头和开集市的年代标出来。若想知道集市为何设在这里，还要找什么记录？ |
| 外语 | 用词族、搭配和对照记单词，用场景学表达。 | 演一次借书。借入的人用 `borrow`，借出的人用 `lend`。交换角色后，同一件事怎么说？ |
| 数学 | 用图形或操作发现关系，用推理说明为什么成立。 | 剪拼一个平行四边形，把它变成长方形。面积为什么没变？新长方形的宽对应原图的哪一段？ |
| 语文与文学 | 用原文细读，用比较体会表达。 | 把人物「挪到门口」改成「走到门口」，再放回上下文读。哪个词更能写出人物当时的处境？ |
| 物理 | 用实验比较条件，用模型作预测。 | 让同一辆小车在同一斜面上从不同高度静止释放，比较到达底端的速度。换一个释放点，先预测再测量。 |
| 化学 | 从看得见的现象提出问题，用粒子模型解释。 | 盐溶进水后看不见了。让水慢慢蒸发，观察留下的晶体，再用粒子图解释前后两次观察。 |
| 生物 | 用结构解释功能，沿过程追踪变化。 | 水从根到叶片，再到空气中，途经哪些结构？借植物剖面图追踪这段路，在水的状态发生变化处作个标记。 |
| 天文 | 用比例认识尺度，用运动和视角解释天象。 | 固定光源，让月球模型绕地球移动。从上方看亮面，再换到地球上观察者的视角，为什么会看到不同的月相？ |
| 工程 | 从需求和约束出发，做原型、测试、改设计。 | 同一张纸跨过相同的间距，平铺和折叠后各能承多重？根据第一次压弯的位置改一次设计。 |
| 信息技术 | 用任务组织步骤，用具体输入检查程序。 | 给计分程序依次输入「答对、答错、再答对」。先写下每一步应有的分数，再找出结果从哪一步开始不同。 |
| 社会与经济 | 用情境呈现选择，用数据比较取舍。 | 比较两条上学路线的路费、耗时和班次。预算相同，但到校时间不同，两个人会怎样选？ |
| 艺术与音乐 | 用对比练习观察和聆听，用创作检验感受。 | 同一句旋律演奏两次，只改节奏。哪一次听起来更急切？再编一个自己的版本，让同伴听听。 |

## 怎样把几种方法用在同一个问题上

**「一座城为什么建在河湾？」** 可以先给学习者一张隐去城址的地图，让他选一个适合设渡口的位置，再揭开真实城址作比较。地图能提出解释，解释是否符合当时的情况，还可以用时间轴对照建城、设渡和通商的先后，再找同时期的地方志或贸易记录。若设渡晚于建城，就值得把「为何在此建城」与「后来为何繁荣」分开追问。

**「怎样读出诗里的人走得有多急？」** 也可以从一句原文起步，圈出写动作的词，录下两种停顿和节奏不同的读法。请同伴选一种，并指出诗里哪个字支持他的判断。这里借用了音乐里的节奏比较，最后仍回到文字本身。
