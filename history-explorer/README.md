# 历史漫游 · 给小小探索家的时光手册

参考 `../primary/history.html` 的历史主题，独立重新编排的静态演示页。面向小学中高年级，按“看见真实材料 → 观察提问 → 动手理解 → 答题回顾”组织学习。

## 打开

直接双击本目录的 `index.html`，用 Chrome、Edge 或 Safari 打开。无需安装依赖或构建。复制整个 `history-explorer` 文件夹即可带走。

图片、15 秒遗址短片、内容和动画均保存在本目录，断网也可使用；三条央视拓展影片及来源链接需要联网。朗读使用浏览器的中文语音，是否可用取决于设备设置。学习足迹保存在当前浏览器本地，清理浏览器数据会清除；浏览器禁用存储时会提示仅本次有效。

如需通过本地 HTTP 浏览，在仓库根目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

打开 [历史漫游本地页](http://127.0.0.1:8766/history-explorer/) 。

## 宽屏布局与主项目风格

独立页采用 `primary-system` 的视觉与布局基线：浅绿纸色、深绿文字、18px 中文基础字号、较大的圆角和按钮，以及一致的品牌页头与页脚。`platform-theme.css` 是 `primary-system/static/platform.css` 的本地快照，图标也保存在本目录，使用时不需要读取主项目文件。

页头、正文 `.shell` 和页脚共用最大 **2240px** 的可用宽度，侧边距为 `clamp(20px, 3vw, 80px)`；小屏按同一套断点减为18px或14px。文字控制阅读行长，图片、文物观察与实验区域随可用空间扩展。

- 视口宽度 **900px 及以上**：`.library-layout` 为左侧学习目录与右侧专题内容，目录宽250–330px，滚动时保持在可见区域。
- **899px 及以下**：目录和内容上下堆叠，目录取消吸顶，可展开或收起；图文区继续按屏幕宽度调整。
- 专题自有样式位于 `.history-topic` 作用域内，便于以后作为主项目的一页使用。

## 页面内容

- **时代长卷**：八个主题、37 条知识线索，切换时代会同步故事、图片、文物、任务和题目。
- **文物观察站**：真实照片、点击放大、先观察再揭晓的小秘密。
- **动手实验室**：丝路五站商队旅行，日/月/山象形猜字，四步造纸工坊。动画由用户启动，可暂停，支持减少动画的系统偏好。
- **历史放映室**：本地 14.739 秒汉长城遗址实拍，以及三条央视拓展影片。文物缩略图为相关文物摄影，不是节目截图。
- **知识口袋**：全文搜索与时代筛选，共37条短知识卡。
- **时光护照**：答对本章题目后手动收集印章，八站分别记录。

正文使用短段落和分层字号，手机、平板和桌面均可使用。对话框支持 Escape 关闭；实验标签支持方向键、Home/End；所有操作均可使用键盘。

## 模板导出

在仓库根目录运行：

```sh
python3 history-explorer/scripts/export_django.py
python3 history-explorer/scripts/export_django.py --check
```

输出 `django/history.html`，只包含 `main#main` 内的 `.history-topic` 专题结构及专题资源引用，不复制独立页的全局页头页脚，也不引用 `platform-theme.css`。旧版历史链接不会进入模板。详细复制位置与最小接入示例见 [INTEGRATION.md](INTEGRATION.md)。

当前没有修改 `primary-system` 应用、URL、模型或入口，也未完成 Django 运行时集成；学习足迹仍保存在浏览器 `localStorage`，尚未接入账号。

## 内容处理

上古传说与已证实的历史分开表达；夏的年代加“约”；说明蔡伦改进造纸术、兰亭序照片为后世摹本、司南为现代复原模型。长城区分明代砖石长城与汉代土筑遗址。路线与汉字动画标明为教学示意，时间轴不按时长比例绘制。
